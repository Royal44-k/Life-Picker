本版把记录、原话、照片、AI 辅助、多页图文、回忆和小拾成长连成一条完整流程。先用自己的一个真实片段试一遍，再逐步使用其他功能。

当前仍需电脑开机运行拾页，iPhone 与电脑连接同一 Wi-Fi。公网部署按你的安排暂停；云同步和真实小红书热榜尚未开通。“最终整合版”指当前本机方案的整合交付。

先试这三个新操作

  1. 找回旧稿：打开作品，滑到工作台底部，点“作品历史”。先“保留当前版本”，修改几句话，刷新后再打开历史。选旧版预览，点“恢复这个版本”。恢复前的现稿也会留在历史里。
  2. 只更新受影响页面：修改原文中的一个章节，点“生成分镜”。来源未变的手改页会保留；对受影响组选择“按新原文更新”或“保留当前页面的表达”，最后确认。锁定页不能直接替换，跨页的同一段会一起确认。
  3. 让 AI 遵循设置：先选独立封面、目录和封底方式，再进入“AI 编辑成篇”。关闭的页面不应出现。生成后如果改了照片选择或作品设置，要重新生成才能应用。

历史保留最近 30 个版本，普通输入约每两分钟留一个恢复点，结构操作前和手动保留会单独记录。历史仅存这个浏览器；作品 ZIP 包含你选择的一个版本及其照片，不包含整份历史。重要版本请单独备份。历史还在用的照片不能永久删除；先备份，再按需清除这篇作品的历史。

① 打开与连接

  1. 如果拾页已经打开，保持电脑服务运行，刷新手机页面即可。首次启动时，在电脑的 D:\Codex-chat-II 文件夹双击启动拾页.cmd。
  2. iPhone 13 连接同一 Wi-Fi，用 Safari 打开启动窗口显示的手机地址。电脑使用 http://localhost:5173。
  3. 在“我的”底部确认显示 v1.6.0 可靠编辑增量。如果仍是旧页面，先收好正在编辑的内容，再刷新。
  4. DeepSeek API Key 已配置时无需重复输入。AI、来源管理和短片需要当前电脑的 8 位连接码；重启服务后连接码会变化。手机不需要填写 API Key。

沿用你已经保存记录的地址。不同手机、浏览器或地址各有自己的内容；换网造成地址变化时，先用旧地址导出备份，再到新地址恢复。源码版本保留不等于个人内容备份。

② 留下一点真实日常

  1. 首页点记下此刻，或“我的 → 随心记与记录备份 → 记一笔”。写一句话、添加照片，之后再补充也可以。
  2. 上传照片后，如果读到了拍摄日期，会出现日期按钮。多张照片可以有不同日期；由你点选采用，不会自动改掉记录日期。
  3. 没有日期信息会明确提示。截图、转存和以前上传的照片可能没有拍摄日期；可直接在“这一天”手填。采用后也能再改。
  4. 照片右上角的 × 只移除本条记录里的照片，可以撤销移除照片。素材库保留原素材；用过的素材受到引用保护。
  5. 想留下好句子，点摘一句原话，长按原文选片段，或点一条断句建议，再“收进原话簿”。
  6. 看到“已保存到本机”后点收好这页。空白页不会虚假保存；失败时保留文字，可重试或下载当前文字。

“我的 → 原话簿”支持搜索、回到出处、移除和撤销。原文以后变化，收藏时的句子仍然保留；最多选 9 句检查公开文案后另存作品。

打开随心记原话簿详细步骤

③ 给小拾换枚书签

小拾是原创纸页精灵，使用轻量 SVG 动画。本地问候、情境问题、保存奖励和装扮不调用 AI。

  1. 进入我的 → 小拾与成长，点一款已经开启的装扮预览。
  2. 点保存装扮才会保存。未保存离开会提示，也可以“撤销预览”。保存失败时选择会保留。
  3. “初见绿”和“晴空蓝”随时可选；收藏第一句原话后开启“花朵邮票”；保存一本回忆册或积累 30 页记录后开启“星光书签”。
  4. 页面显示第一页、第一句原话、第一本回忆、10 页和 30 页纪念。只统计真正保存的积累，已获得的纪念不因删除或断更撤回，没有连续签到要求。
  5. 在随心记右下角点小拾：给点灵感会结合当前文字或“只有照片”的情况提问；它不会声称看懂了尚未提交给 AI 的图片。
  6. 整理这页先收好当前记录，再打开可编辑的公开副本；回看日常按当前记录所在月份打开回忆选材，之后仍能改周、月、年范围。

点“聊一聊”才进入 DeepSeek 对话。默认不附带历史记录或照片；需要时手选本次愿意分享的素材。小拾可以隐藏，打字时安静、键盘出现时避让；沉重记录会轻轻收好。

另一窗口已修改装扮时，本页会提示重新读取，不覆盖新版本。小拾资料会进入完整记录 ZIP；恢复时合并纪念，保留本机已经保存的装扮。

④ 从文字到多页图文

  1. 从“创作”新建作品，或在随心记点“整理为作品”。检查公开文案和附带照片，私藏标签不会自动带过去。
  2. 输入 Markdown：用 # 表示标题，## 表示章节；单独一行 --- 可明确分页。emoji 和颜文字可以保留。
  3. 生成本地分镜，选择自动 / 6 / 9 页目标。拾页按结构和实际文字尺寸分页：短文不凑页，长文会续页或提示限制，不静默截掉正文。
  4. 检查封面、可选目录、观点页、图解与封底。按实际内容选择金字塔、步骤、对比、时间线或清单。单页可改字、换模板、调整照片、调序、锁定、拆分和合并。
  5. 需要 AI 时点AI 润色 / 写文案、整篇 AI 分镜或单页建议。先看结果再应用，原文保留；可以取消，过时结果不能覆盖新编辑。
  6. 点保存单图，在弹窗选择你要的页码，检查实际图片再保存。整篇导出 ZIP，文件名按页码排序。

iPhone 上可长按图片，使用系统提供的存图或分享选项；下载 PNG / ZIP 通常进入“文件”。这里只生成作品，不会自动发到小红书。事实、数字和自己的经历请在发布前核对。

免费方式与费用控制

本地排版、模板、随心记、小拾装扮和原话整理不需要模型费用。AI 面板可以复制提示词到聊天工具，再粘贴结果；已配置 Ollama 的电脑也可用于原有文案能力。DeepSeek 按实际调用收费，使用“我的 → AI 用量与预算”设置月限额、查看估算和待核对费用。不会静默反复重试计费。

⑤ 回头做一本回忆

  1. “我的 → 回忆册 → 做一本回忆册”，或在当前记录的小拾菜单点“回看日常”。
  2. 选择周 / 月 / 年 / 自选日期，点抽取回忆。可以锁定喜欢的片段、排除不想放的内容、换一组，或手动挑选。
  3. 点检查文字与照片。修改本册标题、开场、顺序和照片，原随心记不会被改掉。
  4. 点保存并确认本册。以后刷新或改动原记录，这本回忆仍保留确认时的快照。
  5. 使用预览与下载图文保存指定页或整册 ZIP；或点制作回忆短片选择 15 / 20 / 30 秒。
  6. 短片可以无音乐，或选内置原创轻音。确认发送的是本次选中的回忆画面后，在电脑本机编码 MP4。完成后及时下载，成片约保留 10 分钟。

短片不需要 AI 费用，但需要电脑持续运行。断网时仍保留本册，重新连接后可检查任务；不会把一次超时直接说成取消成功。最大 12 页，每页至少 2 秒，过长会提示缩短或减少页面。

打开回忆册随心记与回忆详细指南

⑥ 持续创作的其他入口

  • 模板：12 种免费原创结构，先替换文字、看预览，再另存作品。开放插画区只展示审核通过的素材，可搭配结构再创作。
  • 首页参考：展示已审核链接、概括、来源和结构分析。可以收藏，或手选 1～3 条自己的记录给 AI 生成选题；未选的历史和标签不会发送。
  • 来源与审核：手工添加参考；固定官方清单的 3 张 CC0 插画可手动检查，也可在电脑运行时每日 09:00 检查。新素材先进入待审核。
  • 个人系列：保存同一栏目的主题、语气和默认外观，用自己的记录写下一篇；改默认设置不会改掉旧作品。
  • 发布与回看：手填发布链接、日期、数据和下一篇想法。空白表示未知，0 表示确认是零，数据未经平台核验。

真实小红书登录采集未连接，因此这里不宣称“近日爆款榜”。首页参考和开放插画检查是两个已有功能，不能等同全网实时热榜。

下载后到 iPhone“文件”确认 ZIP / JSON 实际存在。仅在素材库、从未用于作品或记录的照片，不包含在上述记录备份中。

恢复记录或作品 ZIP 会新增副本，不覆盖现有内容。小拾纪念合并，已保存装扮按本机选择保留；空白设备采用备份里的装扮。损坏文件或照片缺失会拒绝本次导入。

浏览器存储不是永久备份，源码 ZIP 也不包含 API Key、私藏记录和照片。请在清理缓存、换手机或改变地址前，先把需要的内容备份到“文件”。一次完整记录包最多 200 条记录 / 50 本回忆 / 100 张所用照片，超过时按标签或日期分批导出。

⑧ iPhone 13 最终试用路线

  1. 写一条真实记录，选两张照片，采用一个候选日期后再手动改回；移除一张再撤销，确认显示正确。
  2. 摘一句原话，收好记录。进入“小拾与成长”选择“花朵邮票”，保存并刷新，确认装扮和纪念还在。
  3. 打开该记录，点小拾“回看日常”，确认月份对应记录日期。选材、保存一本回忆，导出两页图文或短片。
  4. 把记录或两句原话另存作品，修改第 2 页，使用“保存单图”选择第 2 页，确认下载的是该页；再导出整篇 ZIP。
  5. 可选：与小拾聊一次，确认只附带自己手选的素材，到预算页查看用量。
  6. 下载完整随心记备份。保留这个文件；需要验证恢复时，恢复会新增副本，请辨认新增记录。

桌面自动化已用于验证手机尺寸流程，仍需要这次 Safari 真机验收。重点看 HEIC 选图、长按选字 / 存图、系统键盘、返回操作和长内容滚动。局域网 HTTP 与 HTTPS / localhost 的离线权限不同，当前不要用电脑关机来检验离线能力。

遇到问题时

先保留当前文字和备份，不清空浏览器数据。保存失败用页面的重试或下载文字；另一窗口修改时先保留本页草稿，再“重新载入已保存版本”。图片无法解码可转 JPEG 后重选。AI 无法连接先核对电脑是否运行、当前连接码和预算余额。

v1.0.0～v1.5.0 继续保留。公网部署和商业用户试用后续单独推进。开发验证与各项完成状态见项目 docs/release-v1.6.md 和 docs/shiye-final-scope.md。
