拾页 v1.3 · 本机个人试用指南

从一点真实生活，
写成自己的持续表达。

先记录，再整理；用参考打开思路，用系列留下积累。你可以按下面顺序试用，每一步都能回到“我的”继续。

这是本机个人试用版本，iPhone Safari 的实际体验仍需按文末路线试用。个人小红书尚未连接，不是近日爆款榜；公网访问、云同步和电脑关机后持续运行尚未开通。

① 打开与连接② 文案、照片与指定页下载③ 随心记、小拾与回忆④ 参考与开放素材⑤ 个人系列与发布回看⑥ AI 预算与对账⑦ 备份与恢复⑧ iPhone 试用路线

① 先打开拾页

  1. 在 Windows 的项目文件夹中双击启动拾页.cmd，保持窗口运行。
  2. iPhone 13 和电脑连接同一 Wi-Fi。用 Safari 打开启动窗口显示的手机地址；已经保存过内容时，优先使用原来的地址。
  3. 刷新页面，看到“首页 / 模板 / 创作 / 我的”四个入口。电脑地址是 http://localhost:5173，手机请用窗口显示的局域网地址。
  4. AI、来源管理和短片需用当前 8 位连接码。重启电脑服务后连接码会变化；手机无需输入 DeepSeek API Key。

文字和照片存在当前浏览器。电脑和手机、不同浏览器、不同访问地址各有一份数据。换地址或清理浏览器数据前先下载备份；刷新页面本身不会清空已保存内容。

② 把文字做成多页图文

  1. 进入创作，新建作品并输入或粘贴 Markdown。标题用 # / ##，短段落与列表更适合手机阅读。
  2. 使用本地分镜，按内容生成封面、可选目录和正文等页面。6 / 9 页是目标，短文不会强行凑满，长文装不下会续页或说明限制。
  3. 在素材添加照片，再放到需要的页。上传本身不会调用 AI。需要删掉照片时使用移除；误操作可撤销或去回收站恢复。
  4. 逐页检查文字、裁切与顺序，可选模板、改字号、编辑单页、移动 / 拆分 / 合并。锁定页用于保留已经调整好的排版。
  5. 点保存单图，在弹窗里自己选择页码，确认预览后保存。整篇可以导出 PNG ZIP，文件名有页码。

iPhone 的“下载”一般进入“文件”。若系统提供分享或长按存图选项，可将 PNG 保存到照片。具体系统菜单以 Safari 实际显示为准。

AI 润色和图片看不见时怎么办

“AI 润色 / 写文案”可使用免费手动提示词、DeepSeek API 或已配置的 Ollama。整篇分镜和单页建议先看结果再应用；应用会保留原作品或可撤销修改。事实、数字、自己的经历请逐段核对。

图片无法解码时按提示转换为 JPEG / PNG；HEIC 能否解码取决于实际设备环境。素材丢失时先恢复包含原图的备份，不能只下载文字 ZIP 来找回照片。

打开创作选一种模板

③ 先记下自己的细节

  1. 首页点记下此刻，写一句话、一个声音或一张照片。随心记会自动保存；看到失败提示时先重试或下载当前文字。
  2. 点收好这页。小拾只在实际保存成功后给出奖励；打字时安静陪伴，可隐藏并避让键盘。
  3. 想继续发现题材时，和小拾聊天。只有你明确选中的记录与照片会发送给 DeepSeek；默认不会读取全部历史。
  4. 在我的 → 回忆册按周、月、年或自选日期选材。可以锁定、排除、换一组；确认后保存的是固定快照，原记录保留。
  5. 确认图文后导出指定页、全册 ZIP，或制作 15 / 20 / 30 秒短片。短片使用同一份选材；生成后及时下载 MP4，服务端成片约保留 10 分钟。

记录和回忆可以保持私藏。转成公开作品时先检查独立副本；不会自动发布到小红书。

④ 用参考启发自己的表达

首页参考灵感

首页只显示已经审核的参考：原链接、作者、发布时间或“未知”、收录时间、可核对的观察数值和自己的结构分析。你可收藏，也可点“结合我的记录写一篇”，手选 1～3 条文字，检查将发送的内容后生成选题和草稿。草稿会显示材料依据，另存前需逐段核对。

首次准备来源

  1. 进入我的 → 来源与审核，填写电脑连接码。
  2. 添加自己找到的参考链接，填写题名、作者、自己的概括 / 结构分析。仅参考内容不能当作可自由复用素材。
  3. 检查出处、时间与使用范围后，明确通过审核。编辑已通过的内容会重新回到待审核。
  4. 公开素材任务每日北京时间 09:00 检查固定官方清单，也可手动检查。它先生成待审核候选；电脑停止运行时不会继续采集。

开放插画再创作

首批为 Open Doodles / Open Peeps 的 3 张 CC0 PNG 候选，使用前仍需审核。通过后进入模板页的开放插画区，可搭配拾页 12 种原创结构改写自己的文字，再另存新作品。原图和出处声明随作品备份保留。

固定插画检查不是小红书热榜；本版未连接个人小红书。没有已审核参考时，首页不会编造热度、作者或时间。外部来源断网会提示不可用，12 种原创模板和已有本机作品仍可使用。

管理来源与审核打开模板

⑤ 给自己的创作留一个系列

  1. 打开我的 → 个人系列与发布回看，点新建系列。
  2. 填写名称与关注主题，选择默认文案语气、配色、比例、字号和账号署名，预览后保存。
  3. 点写下一篇，可手选最多 3 条随心记文字放进草稿，再编辑成新作品。复制文字这一步本地完成，不调用 AI。
  4. 已有作品也能在工作台样式面板归入系列。默认保留本篇外观，勾选“同时采用系列默认外观”才套用默认值。
  5. 发布后，在作品里点发布与回看，手填发布链接、日期、互动数据、这次心得与下一篇想法。没掌握的数据留空，0 表示确定是零。
  6. 回到系列页，看每篇作品留下的发现。改系列默认值或停用系列，都不会删除或改写旧作品；停用可恢复。

互动数来自手填，未经平台核验。AI 另存的新篇延续系列主题，旧篇发布数据不会误复制成新篇已经发布。

打开个人系列

⑥ 让 AI 使用有预算

  1. 打开我的 → AI 用量与预算，输入当前电脑连接码并读取。
  2. 默认 AI 月限额为 20 元；你可以调整或关闭新的 AI 调用。改完要点“保存预算设置”。
  3. 查看当月已取得用量的估算、手填核对金额和未知费用预留。取消、断网或服务中断不会直接按免费处理。
  4. 在“只看费用待核对”找到需要核查的请求，打开官方账单确认后手填金额。较早月份也可处理；核对不删除原 token 记录。
  5. 需要留底时点“导出用量账本”。该文件不包含日记、照片、模型回复或 API Key。

默认按 2026-10-05 核对的 DeepSeek Flash 高峰价估算，可展开单价设置查看模型、来源和日期。服务器 + AI 每月 100 元仍是计划目标；服务器实际费用和本工具外的调用没有自动纳入。

预留额度和估算不是官方账单。调用前会检查预算，不会静默重复付费请求；若用量保存失败，生成结果保留，当前服务暂停后续 AI 调用。

⑦ 把积累真正留住

  • 作品备份在创作工作台备份当前作品，包含页面、使用的照片、系列快照和发布回看。
  • 随心记完整备份在“我的 → 随心记与记录备份”下载，包含记录、回收站、回忆快照及引用照片。
  • 系列备份在系列页下载默认设置与主题定义；恢复合并会保留已有同 ID 定义，不覆盖当前设置。
  • 来源备份在来源管理下载。恢复后重新待审核；图片缓存和来源记录分开管理，恢复记录不等于原图已重新下载。
  • 用量账本导出在预算页下载，用于留底和核对，不能当作 API Key 或官方发票。

保存到 iPhone“文件”或自己信任的存储位置。备份可能含私人文字和照片。仅上传到素材库、尚未被作品 / 记录引用的照片，不保证包含在这些内容备份里。

旧版本还能找回吗

v1.0.0、v1.1.0、v1.1.1 与 v1.2.0 的标签和源码包保留在电脑项目中，经典入口仍在“我的”底部。源代码备份不含浏览器里的私人内容。测试旧代码时使用独立地址或浏览器环境，保留当前数据，不通过删库来强行降级。

⑧ 在 iPhone 13 上走一遍

准备一段自己的短文和两张普通照片，按顺序检查实际体验。遇到问题先保留当前文字或下载备份，再告诉我在哪个入口、点了什么、实际出现什么。

  1. 上传两张照片，移除一张、撤销一次，刷新后确认内容正确。
  2. 生成多页作品，选择第 2 页保存单图，在照片或文件中核对是否正是所选页面。
  3. 写一条随心记，弹出键盘输入较长文字，收好后查看小拾奖励是否在保存成功之后。
  4. 用这条记录生成回忆图文，下载一张图；需要短片时生成并保存 MP4。
  5. 建立个人系列，从记录写下一篇，记录一条发布回看；给某项互动数留空、另一项填 0，检查两者显示有区别。
  6. 查看 AI 预算，核对用量与估算；需要时关闭 AI 后尝试调用，确认明确提示，文字仍保留。
  7. 下载作品、记录和系列备份，确认文件能在“文件”里找到。

桌面手机尺寸测试不能替代 Safari 真机。请特别留意 HEIC、键盘遮挡、滚动、长按保存和系统分享。局域网 HTTP 不具有 HTTPS / localhost 的全部 PWA 权限，不承诺此环境中关闭电脑后仍完整可用。
