拾页 1.1.1：从原文到一组作品

先用一篇自己的短文试一遍。新工作台会保留原文，并把页面修改另行保存。

当前版本在电脑本地运行。iPhone 与电脑连接同一 Wi-Fi，用 Safari 打开启动窗口里的手机地址。电脑关闭后暂时不可访问；公网部署尚未完成。

1. 写原文，生成分镜

  1. 点右上角“＋”新建作品，进入“原文”。粘贴文字，或点“导入文字”选择 Markdown/TXT。
  2. 用 # 总标题、## 小节标题 组织文章。单独一行 --- 表示你指定的分页。
  3. 选择自动、尽量 6 页或尽量 9 页，以及封面、目录和结尾方式。
  4. 点“生成分镜”。内容过多时保留全文并增加页数，不会为了凑页而删文。

2. 加入自己的照片

  1. 进入“素材”，点“添加照片或截图”，可从 iPhone 相册选择照片。
  2. 点击照片下面的“用作封面照片”。其他页面可在分镜编辑里选择“搭配照片”。
  3. 照片可选填满画面或完整显示，并调整左右、上下取景。

每次最多 10 张、单张最多 20 MB；会保存一份最长边不超过 2048px 的排版副本，手机相册原图保持不变。HEIC 无法读取时，先导出为 JPEG 再添加。

删除与撤销：点照片下方“删除”，确认“移入回收站”。删除后可以立即撤销，或从素材页右上角“回收站”恢复。已经放进作品的照片仍正常显示；永久删除前必须先解除作品引用。这里只删除拾页副本，手机相册原图不受影响。

3. 调整每一页

  1. 进入“分镜”，点缩略图或标题。
  2. 修改“本页文字”，可选择文字卡、金字塔、步骤、对比、时间线或清单。
  3. 图解每项写在一个独立段落或列表项；金字塔需要 3～5 个真正有层级的项目。文字过长会完整回退到文字卡，并显示提示。
  4. 满意后点“锁定本页”，避免重新编排覆盖。可解锁后继续修改。
  5. 分镜列表支持上移、下移、删除、添加页面；编辑窗口支持拆为续页和合并下一页。重新生成时锁定页保留，注意检查重复内容。

12 种结构模板：在“样式”点“选择结构模板”，先选择要修改的分镜，再选模板。下方会显示套用你自己内容后的真实预览，检查后点“应用到第 N 分镜”。也能在单页编辑里点“更换本页模板”。内置模板可免费使用，不调用 AI；锁定页先解锁，自动目录保持目录布局。

只改这一页：在单页编辑点“AI 只改这一页 · 先看建议”。选润色、精简或改善开头，按需勾选原文上下文，填写 8 位连接码。默认只发当前页文字，不发照片和其他记录。生成后对照原句，编辑建议，再应用；分镜列表可撤销。等待时可取消，旧版本建议不能覆盖新修改。

“查看这页对应的原文”可核对来源。原文变化后，旧位置会暂停显示，避免误用。目录页码会随真正的图片页数更新，包括续页。

4. 使用 AI 编辑成篇

  1. 进入“原文”，点击“AI 编辑成篇 · 先看建议”。
  2. 填写电脑启动窗口中的 8 位 AI 连接码。密钥继续保存在电脑的 .env 中，手机无需填写 API Key。
  3. 需要看图建议时，勾选“附带本作品使用的照片”；最多发送 3 张，默认不发送照片。
  4. 点“生成分镜建议”。可以取消，失败时保留原作品。
  5. 逐页检查文字，展开“查看对应原文”核对来源。点“应用为新作品”，原作品留在作品库。

AI 会精简和重组，请核对事实、数字和个人经历。换颜色、调字号和本地分页不会调用模型。普通润色与从主题写作仍可用“AI 润色 / 写文案”。

5. 保存图片到 iPhone

  1. 在“样式”选择主题、比例、文字大小、署名与系列名。
  2. 进入“预览”，逐页查看；原文有变动时，请先回到原文重新生成分镜。
  3. 点底部“保存单图”，先从“选择要保存的图片”选择页码，也可用上一张/下一张切换。确认“第 N 张”后，长按图片存到“照片”，或点“下载 PNG”。文件名带对应页码；系统分享取决于浏览器支持。分镜列表的下载图标也能直接打开对应分镜。
  4. 整篇点“整篇 ZIP”，在“文件”中找到下载并解压，按 01、02、03 的文件名顺序发布。

单页编辑自动保存。若显示“修改尚未保存”，当前文字会保留；按提示处理后点“重试保存”。“保存并关闭”会等待保存成功才关闭，避免误以为已保存。

6. 备份与恢复

页面下方“备份作品”会导出原文、页面修改、锁定状态及作品使用的照片。换设备时用“恢复备份”导入，生成一份新作品。仅存在素材库、尚未放进作品的照片不包含在该作品备份中。

本机保存不是云备份。清除 Safari 数据或更换访问地址后，本机作品可能不可见；重要作品请先备份。出现“另一窗口已更新”时，先备份当前修改，再刷新，避免互相覆盖。

经典版与 v1 保留

右上角“经典版”可继续使用原来的工作台。原草稿会复制到新作品库，经典版里的数据仍保留。开发目录 releases 保存了已核验的 v1 源码归档，并有 Git 标签 v1.0.0。

随心记、小拾、回忆相册和灵感更新按后续阶段开发，当前指南仅描述已接入的 1.1 创作工作台。
