拾页首页来源与审核之前功能指南

拾页 v1.10.0 · 外部来源连接版

从有出处的灵感，写回自己的生活。

先保存当前编辑，再刷新原来的拾页地址。v1～v1.9 与本机记录保留；本版仍需电脑开机、手机与电脑在同一 Wi-Fi。

1. 连接来源库

  1. 打开“我的 → 来源与审核”。
  2. 填写电脑服务启动日志中的 8 位连接码，点“连接来源库”。电脑服务重启后，连接码会变化。
  3. 下面分别显示个人小红书、公开插画检查和开放设计发现。这些操作不调用 DeepSeek，不产生 AI token 费用。

2. 读取个人小红书参考

  1. 首次点“打开电脑登录窗口”，在电脑弹出的拾页专用 Edge 窗口正常扫码登录，登录资料仅留在本机。已经登录可直接点“检查登录状态”。
  2. 检查或采集可能在电脑打开窗口，工作时先不要操作它。
  3. 选择“本人推荐页”，或“按关键词找参考”并输入主题。最近一周选项会核对“最新、图文、一周内”三项网页筛选及结果刷新。
  4. 点“获取参考 · 最多 6 条”。只收录标题、作者、原链接和可见点赞数，先进入下方待审核来源夹。
  5. 要结束时点“停止个人来源”，会关闭专用窗口并保留登录。若提示窗口占用，关闭之前的专用窗口（不要退出登录）后再检查。

这是本人网页可见参考，不是官方开放 API、全站爆款榜或流量保证。页面变化、登录失效、安全验证、访问限制或网络超时会中止操作，不会把错误记成零条成功。未明确取得的发布时间保持未知。

每日 09:00 更新需成功手动采集后自行开启；电脑必须运行，任务可能打开专用窗口。访问受限时暂停，需本人检查。

3. 查找免费开放设计

  1. 在“发现开放设计”选择 Marp 或 reveal.js，点“查找开放设计”，无需 GitHub 账号或 API Key。
  2. 每次最多查询 6 个项目，逐个读取 MIT 许可。可打开“查看原项目”“许可原文”。
  3. 感兴趣的点“加入待审核”。重复项目不重复添加，不覆盖你正在写的观察。
  4. 这里是待适配源码参考，不能直接当作拾页模板套用。适配时仍需检查项目里的照片、插画、字体与插件，保留许可声明。

现有 14 种可用结构仍在模板广场，其中两种开放主题已完成适配。新项目不计入可用模板数量。候选列表随服务重启清空，超过一天需重新检查；已入库的来源与许可证明保留。免费接口限流或网络失败时，请稍后手动重试。

4. 审核后使用

  1. 在“我的来源夹”打开待审核条目，阅读原链接。
  2. 写下自己的概括或结构分析，核对出处与使用范围后保存。
  3. 勾选确认，再“通过审核”。参考才会进入首页；编辑后会重新待审核。
  4. 插画另用“检查公开素材更新”核验 7 项固定 CC0 清单，通过后在广场搭配原创版式。插画是装饰素材，与可编辑模板分开显示。

结合自己的随心记、照片与经历创作；定期导出作品、记录和来源备份。

遇到问题

手机连不上：检查电脑开机、同一 Wi-Fi、原地址是否变化。连接码错误：使用本次启动的新码。只有部分素材成功：展开失败原因，已保存内容保留。不需要清空账号或关闭 Windows 防护来排查。

公网与云同步继续暂停；iPhone Safari 的系统保存和实际体验，仍需在手机验收。
