第一次试用 · iPhone 13

不用懂开发，也能做出第一组图文。

这版由你的 Windows 电脑提供服务，iPhone 的 Safari 负责使用。暂时不需要安装 App、注册账号或购买服务器。

1. 让电脑和手机连接起来

  1. 在电脑打开文件夹 D:\Codex-chat-II。
  2. 双击 启动拾页.cmd。看到“拾页已启动”后，保持窗口开着。若提示端口已用，通常表示拾页已经运行，直接打开窗口给出的地址。
  3. 让 iPhone 和电脑连接同一个 Wi-Fi。不要只用手机蜂窝网络。
  4. 在 iPhone 打开 Safari，把电脑窗口显示的“iPhone 同一 Wi-Fi 打开”地址完整输入地址栏。地址类似 http://192.168.5.25:5173，以你当时窗口显示的为准。
  5. 看到“让好内容，自成一页”即成功。不要在手机输入 localhost，它会指向手机自己。

先在自己可信的家庭 Wi-Fi 试用。局域网 HTTP 不加密；手机只输入临时 AI 连接码，真正的 API Key 留在电脑端。不要向路由器配置公网端口转发。

2. 完成第一组卡片

  1. 点 内容。先用内置示例，或全选替换为你的文字。
  2. 标题前加 # （井号后有空格）。想另起一张卡片，在单独一行写 ---。
  3. 点 样式，先选“紫序”和“3:4”。改“账号署名”为你的小红书昵称。
  4. 点 预览，点击底部小卡片或左右箭头逐页检查。太挤就减小字号，或回内容中调整分页。
  5. 点 导出图片。长按弹窗里的图片，在 iOS 菜单选择“存储到照片”或“添加到照片”（文字依版本而定）。
  6. 点 下一张，逐张保存。打开 iPhone“照片”确认图片清晰、文字完整。
  7. 打开小红书，点发布入口，从照片中按顺序选图，检查后自行发布。

若长按没有出现保存选项：试试“系统分享 / 保存”（在支持文件分享的 HTTPS 环境显示）；或点“下载此张 PNG”，从 Safari 的下载列表/“文件”打开图片，再点分享 → 存储图像。

“打包 ZIP”会保存为压缩包，适合电脑批处理及备份，不会自动将多张图片存进 iPhone 相册。

3. 使用 AI 文案助手

在“内容”上方点 让灵感，再向前一步。选择“润色已有文案”或“从主题生成”，调整语气、目标长度和符号风格。想要颜文字可选择“适量 emoji 和颜文字”。

先免费体验，不配置 API

  1. 使用方式选“免费手动”。
  2. 点“复制完整提示词”，到你常用的聊天工具粘贴生成；也可点“打开 DeepSeek”。服务商免费额度以其页面为准。
  3. 复制生成的文案，回到拾页，粘贴到“将生成的文案粘贴到这里”。
  4. 点“应用到排版”。新稿自动成为一篇新草稿，原稿仍留在草稿箱。

局域网 HTTP 下自动复制可能不可用。拾页会把提示词放入独立的“完整提示词”文本框；长按文本框 → 全选 → 复制即可。

接入 DeepSeek，实现一键生成

DeepSeek API 按量收费，和免费聊天网页是两项服务。查看 官方当前价格。

  1. 先在“使用方式”选择 DeepSeek。若显示“当前模型”，代表电脑已有配置，可直接跳到第 5 步。
  2. 在电脑访问 DeepSeek 开放平台，登录并在 API Keys 页面创建密钥。余额和充值由你自行管理。
  3. 双击项目里的 配置AI.cmd，会打开电脑上的 .env 文件。
  4. 把密钥放在 DEEPSEEK_API_KEY= 的等号后面；不要加空格。保留 DEEPSEEK_MODEL=deepseek-flash。按 Ctrl+S 保存并关闭记事本。回启动窗口按 Ctrl+C 停止，再双击“启动拾页.cmd”。不要把这个文件发给别人。
  5. 在手机 AI 面板填入电脑启动窗口显示的 8 位连接码，不是 API Key。重启后连接码会变化。
  6. 点击“开始润色”或“生成文案”，等待结果。检查事实、数字和语气，再点击“应用到排版”。

文案会发送给 DeepSeek；只有你点击生成时才请求服务。每次生成最长等待 75 秒，输出限制 2,600 tokens；未自动循环重试。没有成功结果时保留原稿。

可选：Ollama 本地模型

本地模型无 API 费用，但占用电脑内存、磁盘和电力，需要电脑持续运行。初次试用建议先用上面的免费手动方式或 DeepSeek。

  1. 到 Ollama 官网安装 Windows 版，并根据你的电脑配置选择模型。
  2. 按所选模型官网说明运行 ollama pull 模型名称。下载可能有数 GB；不要直接复制“模型名称”四个字。
  3. 在 .env 中把 OLLAMA_MODEL= 改为你实际安装的完整模型名称。重启拾页。
  4. 手机选择“Ollama 本地模型”，输入连接码后生成。若提示找不到模型，检查名称是否与 ollama list 一致。

4. 草稿和批量处理

草稿自动保存在当前浏览器。电脑和手机各自保存，不会自动同步；换浏览器、清除网站数据或更换访问地址后可能看不到旧稿。重要文案请先备份。

  1. 电脑端可点“备份原文”下载 Markdown。手机端请在“内容”面板使用“备份原文”。
  2. “导入”支持一次选择最多 10 个 .md / .txt 文件。
  3. 打开“草稿箱”，选中需要的多篇，点“批量导出”。ZIP 中每篇一个文件夹，图片按 01、02 排序。

每篇最多 20,000 字符、60 页，最多保存 20 篇草稿。高级 Markdown 表格、外链图片和公式暂未支持；特殊字体和 emoji 外观随设备变化。

5. 打不开时，按这个顺序检查

  1. 电脑打开 http://localhost:5173 是否可用？不可用先重新启动拾页。
  2. 核对手机输入的是电脑窗口当前的 IP 地址。电脑换 Wi-Fi 后地址可能变化。
  3. 确认同一 Wi-Fi，避免访客 Wi-Fi；访客网络常禁止设备互访。必要时暂时关闭 VPN 后再试。
  4. 若 Windows 出现 Node.js 防火墙提示，只允许你信任的专用网络；不要关闭整个防火墙。没有提示时，可检查 Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙中的 Node.js 专用网络项。
  5. 仍不行，把 Safari 显示的报错文字告诉我，我会按实际错误继续排查。

6. 关于添加到主屏幕

Safari 的分享菜单里可尝试“添加到主屏幕”，方便下次打开。当前局域网 HTTP 试用仍依赖电脑在线，不等于安装了可离线的原生 App。完整 PWA 离线缓存与系统分享需要 HTTPS 上线环境；本版本已准备相关文件，但尚未公开部署。

第一次试用，帮自己记下 4 件事

① 从粘贴到保存用了多久？② 哪一页需要手动改？③ 相册中的文字是否清楚？④ AI 文案有没有改变原意？先拿一篇自己的真实文案做完一次，这比增加模板更能判断工具是否有用。
