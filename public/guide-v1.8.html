拾页首页创作排版及之前功能

拾页 v1.8.0 · 开放模板与视觉建议增量

有依据地选样式。

保存正在编辑的内容后刷新原拾页地址；在“我的”底部确认 v1.8.0。旧版本、作品和随心记保留，公网部署继续暂缓。

① 从开放主题开始

  1. 进入“模板”，找到开放主题，选择“暖纸讲义”或“白纸蓝标”。
  2. 输入自己的文字，查看实际预览和作者、完整 MIT 许可、改动说明。
  3. 点用开放主题另存作品。之前的作品仍保留，可继续修改文字、配色、页序与照片。
  4. 开放素材候选由 3 项增加至 7 项。进入“我的 → 来源与审核”手动检查固定素材，审核后才会出现在素材入口。

主题是依据 Marp Gaia / reveal.js White 规则做的本地适配；无需加载远程字体或代码。来源和许可跟随软件保留。

② 让 AI 提议一种视觉风格

  1. 在作品预览选中需要调整的页，进入“样式”，点AI 视觉试配 · 先看预览。
  2. 查看本次发送的文字，输入想要的感觉和电脑的 8 位 AI 连接码，点生成视觉建议。只有这一步会调用 DeepSeek 并计费。
  3. 对比“当前页面”和“试配以后”，查看推荐依据。结构只改选中页，配色影响整篇；作品有锁定页时保持整篇配色。
  4. 满意后点确认应用视觉建议。文字、原文与照片不被改写；不满意可以关闭或取消。
  5. 样式页点撤销上一步，或使用“作品历史”恢复。保存失败时弹窗保留且明确提示；不要直接刷新丢掉未保存修改。

照片像素、其他页和全部随心记不会随这次视觉请求发送。模型只返回已支持的主题、模板、颜色与理由，不执行模型生成的代码。费用在“我的 → AI 用量与预算”查看。

③ 个人参考的当前状态

本机尚未连接真实小红书账号。已核验固定工具与浏览器依赖；真实检查发现 Windows 错误 225，拦截了上游进程辅助器。此时来源保持停止，不要关闭系统防护或添加排除项。可以继续手动添加原链接、作者和自己的观察，审核后作为灵感。

运行环境正常时的入口为“我的 → 来源与审核 → 个人小红书参考”：本人正常扫码 → 检查登录 → 选择推荐页或关键词 → 获取最多 6 条 → 补充自己的概括与分析 → 审核。不会自动发布、点赞、评论，也不复制笔记全文或图片。

首次成功手动获取后才可主动开启每日 09:00 检查。电脑需要运行；失去登录、平台验证、访问限制或其他错误会停止并关闭自动检查。最近一周筛选是网页返回结果，不是全站实时热榜。未知日期、互动数保持未知。

电脑准备步骤
  1. 在项目目录运行 npm run setup:xhs。首次准备约下载 190 MB 浏览器依赖及服务程序，必须校验通过。
  2. 重启拾页后刷新来源状态。文件只放在拾页自己的 .local 目录；源码备份不包含登录状态。
  3. 若仍显示错误 225，保持停止并使用手动来源；不要为试用关闭系统防护。

④ 本次试用重点

  2. 对自己的短文做一次视觉建议，比较、应用、撤销，确认照片和正文完整。
  3. 在 iPhone 13 检查字号、键盘、照片选择和长按保存；电脑手机视口测试不能替代真机。
