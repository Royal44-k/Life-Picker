# 拾页 v1.4.0：原话簿

2026-10-07。本机个人试用增量，承接已批准方案中的原话收藏。

## 这次新增
- 随心记可摘取原文片段，或点选断句建议。每句最多 500 字符，每条记录最多 20 句，同一记录避免重复收藏。
- 原话簿集中搜索收藏、回到原记录、移除和撤销最近移除。原话保留收藏时的日期及文字，原记录改写不会覆盖快照。
- 选择 1～9 句，按选择顺序检查可编辑的公开文案，再另存新作品。未选的内容、标签、照片、内部身份均不自动附带；不自动发布。
- 原话随来源记录备份、回收和恢复。恢复 ZIP 创建新的记录身份，原话出处相应指向恢复后的记录。永久删除记录前说明原话一起删除。

## 使用
“我的 → 原话簿”，或在随心记里点“摘一句原话”。详细操作见 public/guide-v1.4.html；完整原有功能继续见 guide-v1.3.html。

云部署、购买和注册暂缓。仍采用电脑运行、同一 Wi-Fi 的本机服务。浏览器数据没有云同步；重要记录先在随心记里完整备份。新收藏流程不调用模型，不新增 AI 费用；整理到工作台后可主动使用已有 AI 润色。

## 验证范围
154 项模块测试通过，覆盖真实摘录、快照、去重、上限、回收、撤销、公开边界、旧格式和损坏 ZIP。
新功能手机尺寸浏览器覆盖完整采集到作品、备份新身份、原文变更、保存失败和跨窗口冲突。受影响的导航、随心记、小拾、记录存储与回忆回归通过。
生产离线验证完成收藏、刷新、新作品和指定第 2 页真实 PNG 1080×1440 导出，以及指南缓存。测试在 Windows Edge 390×844 独立浏览器上下文中完成，不代表 iPhone Safari 真机已验收。
