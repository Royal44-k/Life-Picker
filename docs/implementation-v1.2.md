# 拾页 v1.2 实施计划：记录到作品

状态：v1.1.1 已审查、修复、标记及归档，当前正在实施；承接 docs/shiye-next-design.md 和用户持续开发授权。阶段测试由开发端执行，用户在整体可试用后统一验收，不重复要求阶段确认。

## 交付顺序
1. **记录与共享素材安全**：IndexedDB 添加 journals / memories；所有事务有明确错误、修订检查。照片回收站与永久删除检查扩展到作品、随心记、回忆；不能因增加新入口而破坏现有引用保护。旧 stories / assets 保留并有迁移测试。
2. **随心记闭环**：文字、多张照片、日期、标签、搜索、时间线、自动保存、撤销/回收、续记“后来怎么样”、完整备份恢复。保存状态清楚，失败保留编辑；首次空白不生成垃圾记录。选中记录可另存为公开创作草稿。
3. **小拾陪伴与灵感**：原创 SVG 纸页精灵，奶油纸页/小折角/墨点眼睛/杏色脸颊/嫩绿书签。离线固定引导，打字安静，键盘避让，可隐藏，尊重减少动画。只有真实保存成功才短奖励；沉重情绪选择安静回应。聊天只发用户当前选择的文字/图片和本会话，DeepSeek 按量调用，可取消与失败保留输入；不默认读取历史随心记。
4. **回忆选材与图文册**：周/月/年/自选范围，本地多日期抽样、锁定、排除、换一组；保存快照后不因刷新变样，后续原记录变化只提示不偷偷改册。用户确认选材和文字，再生成图文作品副本。空范围不造内容，少量记录允许短册。
5. **回忆短片**：从同一已确认图文册画面生成 15～30 秒 MP4，无音乐默认。明确发送所选画面到本机渲染服务；FFmpeg 单队列、上限、作业状态、取消/失败重试、短期清理。验证实际视频画面/时长/尺寸与选材一致。不把未安装 FFmpeg 或未部署的能力当作已完成。
6. **四入口与交付检查**：首页/模板/创作/我的导航，首页继续创作/最近记录/回忆入口，我的含随心记和备份。检查 iPhone 尺寸、键盘遮挡、离线记录和实际图文/视频文件；一次独立审查，修复后归档。

## 统一边界
- 当前环境为个人电脑 + 局域网，浏览器素材不会自动跨设备同步；公开部署、用户隔离及持续在线采集按真实环境另行验证。
- 原始随心记与导出的公开副本分开，默认不附私藏标签和未选原话。记录/照片/回忆不会自动发给 AI。
- 重用既有连接码、请求校验、取消、限流；不引入新模型供应商或订阅费用。
- 音乐、外部图片或字体只有逐项核实可复用时才纳入，不为了视觉效果增加未清楚授权的素材。
- 所有成功提示依赖真正完成的存储/作业结果；选图、删除、选择导出页等已经修复的交互应在新入口保持一致。
