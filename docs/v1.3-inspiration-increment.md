# v1.3 灵感与素材创作：当前开发增量

本增量已完成本地实现和回归，尚未发布整个 v1.3。继续开发个人系列、发布回看与用量预算后，再统一试用验收。

## 可以做什么

- 首页的“参考里的写作灵感”展示已审核参考，能看原始出处、结构观察、已记录的互动数和观察时间。缺少发布时间或互动数会明确显示未知。可在当前浏览器收藏参考。
- 模板页保留 12 种原创结构，并新增“已核验插画”。通过审核的 CC0 PNG 可以搭配自己的文字，先看真实排版，再保存为新作品。失败时文字保留；重新核对素材也不会清空输入。
- 首页参考卡片可“结合我的记录写一篇”：手选最多 3 条文字记录，先核对将发送的内容，生成选题和草稿。照片、标签与未选记录不会随请求发送。可使用 emoji / 颜文字风格。
- AI 建议只是草稿。短材料不强行扩写；先逐段删除或修正原文没有的经历细节，再另存新作品。原始随心记保留，其他窗口更新记录会阻止使用过时建议。
- 素材作者、许可和原始链接随作品备份保留，可在工作台查看。已经套用到作品的原图在断网后仍能导出；外部参考列表本身需要连接电脑。

## 当前边界

- 实际来源库已有 3 张官方插画候选，仍等待用户审核；开发验证使用隔离来源库，没有把测试审核写入用户数据。
- 个人小红书来源尚未连接，所以首页不冒充实时爆款热榜。可以先通过“我的 → 来源与审核”录入自己的参考并核对出处。
- 收藏列表属于当前浏览器偏好，尚不包含在作品 / 随心记备份；原始参考资料通过电脑端来源备份保存。
- 两次真实模型试验共 2,066 tokens，输入均为独立测试样本。人民币费用与月度预算控制将在下一任务实现，不能把 token 数当作账单。
- 已验证 Edge 390×844、真实官方 PNG、生产离线壳和一次修正后的真实 DeepSeek 输出；iPhone Safari、个人小红书正常登录及公网部署仍需真实环境验证。

## 开发验证

`npm test`：127 项通过。另通过 8 个存储脚本、4 个来源浏览器脚本、2 个灵感创作脚本、2 个导航脚本和 5 个离线脚本。

`npm run test:inspiration:offline` 使用本机已核验的 `.local/source-catalog/5173` 与 `.local/source-assets/5173`，以及 5181 生产预览；它只把候选复制到临时来源库审核，在新浏览器上下文创建测试作品，结束后移除临时库。首次恢复项目时需先让公开素材任务成功核验 3 张原图，不能将缺失缓存伪装为通过。

详细任务记录：`docs/implementation-v1.3.md`。真实素材证据：`docs/public-assets-verification.md`。
