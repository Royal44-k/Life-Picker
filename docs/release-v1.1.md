## 本轮可用能力

文字 / Markdown 分镜、可选封面目录结尾、照片素材、页面文字修改、移动锁定、拆分合并、五类图解、主题与比例、AI 分镜建议与来源预览、1080 宽 PNG / 顺序 ZIP、带照片的作品备份恢复、复制迁移旧稿。

6/9 页为软目标。分镜与实际图片数分别显示：大字号、照片占位等导致内容超出一张时，会产生续页。导出消费当前页面及顺序，不回到原文重新生成另一份作品。

## 本轮修复

1. 60 页旧稿加封面导致整个工作台无法初始化：迁移不强加封面；单篇超限仍完整复制原文，其他作品可继续使用。
2. 长稿超过规则分页上限时 AI 弹窗白屏：模型来源分块与打印页数分离。
3. 原文重排丢照片：匹配页面保留图片、取景与 ID；无法匹配时明确提示重新搭配，原照片仍在素材库。
4. 超长页面合并后无法保存也无法备份：候选作品在界面和保存队列变更前校验，拒绝操作后正常编辑和备份仍可用。
5. 目录误收代码中的示例标题：从解析后的实际 heading 提取。
6. 手动拆页损坏跨页代码格式：续页继承围栏状态。
7. 批量导入第二篇失败时第一篇已落库却未显示：改为单事务整批写入。

每项都有针对性回归；关键修复先观察失败，再修复至通过。
