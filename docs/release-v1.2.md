# 拾页 v1.2.0 发布记录

2026-09-29。个人局域网试用版本；完整功能、独立审查及修复已通过自动化检查，按 v1.2.0 保留源码与校验。本版本不是完整路线图或公网服务交付。

## 这版带来的变化
- 首页 / 模板 / 创作 / 我的四入口贯通，日常记录与图文创作形成连续流程。首页最近内容来自当前浏览器，本地灵感不冒充网络热榜。
- 随心记支持文字、照片、日期、标签、收藏、搜索、关联续记；自动保存、失败重试、回收恢复、完整 ZIP 备份，公开前检查可编辑副本。
- 小拾采用原创 SVG 纸页精灵：本地问题、真实保存奖励、安静陪伴、隐藏与键盘避让；聊天接入已有 DeepSeek，默认不选历史，手动勾选最多 3 条记录与 3 张压缩照片。
- 回忆册按周 / 月 / 年 / 自选日期挑选，锁定、排除、换组及手动选材；核对文字照片后保存固定快照，原记录后续变化只提示。指定页 PNG / 全册 ZIP 与公开作品共用相同确认画面。
- 短片从同一确认画面生成 15～30 秒、720×1280 MP4，照片轻动而文字固定。默认无音乐，可选项目自制合成轻音。明确发送确认、单队列、取消重试、同会话刷新找回和实际下载。
- 12 种原创结构模板可在独立入口修改示例、查看真实分页并另存作品；既有作品保留。用户反馈中的照片移除 / 撤销和任意页单图保存继续回归通过。

## 当前环境与不能替代的验收
- 这是电脑运行 + 同 Wi-Fi 的个人试用工具，尚未部署公网 HTTPS、账户、跨设备同步或关机后持续采集。
- Edge 390×844 与 localhost 的离线检查，不能替代 iPhone 13 Safari 的键盘、HEIC 解码、系统分享及真实模型文案效果验证。由用户在整体完成后统一试用。
- 随心记、作品和照片存于当前浏览器。变更访问地址、更换设备或清理浏览器数据前需下载备份；没有后台自动云备份。
- 外部灵感 / 模板来源收集、许可审核、个人系列与发布回看仍属于 v1.3；当前不展示伪造的近日爆款。

## 阶段设计取舍清单

以下顺序与实施记录一致；详细验证与适用边界见 docs/implementation-v1.2.md。

- Ruling：先扩展共享照片引用保护再添加随心记，避免新入口产生可被旧回收站永久删除的悬空引用。
- Ruling：短片默认采用已经确认的图文册画面作为帧源，保障图文与视频选材、文字、顺序一致；先不增加生成式视频或音乐费用。
- Ruling：共享数据库结构升级至版本 2，以一个事务完成跨入口引用保护。不能用旧 v1.1.1 代码直接读降级数据库；经典 v1 使用原独立存储仍保留，回退/迁移以备份恢复而不是强行降级数据库结构。代价是旧代码回退时需重新导入备份。
- Ruling：回忆快照不跟随原记录后续修改；删除原记录后，已确认快照仍保留其文字和照片引用。后续 UI 必须清楚标记快照和删除影响。
- Ruling：编辑记录时收起小拾问候，不在失焦时自动再展开；主动点击和保存成功仍可展开，避免按钮点击期间界面移动或遮挡。
- Ruling：回忆增加可选开场文字（4,000 字符上限，计入总 16,000），单独生成开场页；图文和后续视频均从同一画面生成，避免视频另写一份文案。代价是短片篇幅限制需要用户另存精简册，而不能偷偷删页。
- Ruling：相册公开副本保留当前确认日期并明确让用户检查；可在创作台编辑，当前没有“自动隐去全部日期”开关。
- Ruling：用每端口独立任务目录，避免开发服务重启误删生产服务作业。当前会话隔离适用于本机个人试用服务，不能据此声明云端账户权限体系已完成。
- Ruling：可选背景音乐先提供自行合成的一段轻音，避免引入外部录音许可与订阅依赖；代价是暂不提供音乐曲库或用户上传音乐。默认无音乐与现有图文一致性保持。
- Ruling：地址保留当前作品/已保存记录 ID，首页直达内容后再新建或切换也同步地址。刷新回到当前编辑对象，避免旧入口参数覆盖最近选择；代价是地址只在拥有同一份本机数据的浏览器中有效，不能当作分享链接。
- Ruling：现有测试用明确 view=studio 路由；夹具中直接替换活动作品时同步 URL 中的 id，保留原超限合并/保存/导出断言。测试初次失败为夹具仍只改 localStorage，不是删掉断言以掩盖缺陷。
- Final: Ruling: 云端账户、跨设备、HTTPS 与关机采集尚未部署；本阶段只声明本机个人试用，后续需真实环境验证。代价是当前电脑关闭时无法提供远程服务。
- Final: Ruling: iPhone Safari 键盘、HEIC 和系统分享保留真机待验收标记，桌面视口不能替代。代价是可能存在尚未发现的设备兼容问题。
- Final: Ruling: 审查不新增真实模型调用；已验证接口和人工确认流程，文案质量与经常性费用仍需后续真实使用证据。代价是模型输出质量与月费用尚无试用统计。
- Final: Ruling: FFmpeg 二进制不包含在源码发布中，运行时路径、发布者来源和校验已单独记录；未来分发二进制需单独处理许可。代价是新电脑需配置该运行时后才可生成短片。
