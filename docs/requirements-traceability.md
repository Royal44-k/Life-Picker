# 用户需求、实现与后续工作

截至软件 v1.10.0；归档复核日期 2026-10-17。功能实现、外部环境和商业效果分别判断。

| 用户目标 | 当前实现 / 入口 | 证据与限制 |
| --- | --- | --- |
| 手机优先，iPhone 13 自用 | Web / PWA、390px 布局、四入口 | 用户确认首版能打开；Safari 系统保存等仍需真机完整验收 |
| 文字 / Markdown 批量做图 | core、studio；PNG、整篇 / 经典批处理 ZIP | 内容守恒、1080px、实际导出验证；Markdown 是明确子集 |
| AI 润色、写作、符号与颜文字 | AI 文案面板，DeepSeek / Ollama / 手动路径 | 主动提交、预览、应用为新稿；免费本地模型需另行安装 |
| v1 保留 | 经典入口、独立旧存储、12 个标签与原始包 | 恢复旧版需独立地址，不能强行降级数据库 |
| 智能 6～9 页编排 | 章节树、页面角色、实测容量、拆册 | 软目标，不能保证每篇恰好六或九页 |
| 图片上传与可删除 | 共享素材、移除 / 撤销 / 回收 / 引用检查 | v1.1.1 用户反馈回归 |
| 指定任一页下载 | 单图页码选择，预览与导出同源 | 真实单页 PNG 验证 |
| 好看的模板广场 | 12 原创结构 + 2 开放主题适配 | GitHub 候选与可用模板严格区分 |
| 随心记录文字与照片 | 随心记、标签、收藏、日期、续记、备份 | 本机 IndexedDB；不是自动云备份 |
| 萌数字人、引导和保存奖励 | 原创小拾 SVG / CSS、情境问题、保存成长 | 本地动作不消耗 AI；不是 3D 或语音数字人 |
| 与小拾聊天 | 手选记录 / 照片后请求 DeepSeek | 默认不发送历史；模型建议需核实 |
| 周月年回忆相册 | 多日期选材、锁定 / 排除 / 换组、固定快照 | 记录较少生成较短内容，不补造经历 |
| 回忆短片 | 15 / 20 / 30 秒，本机 FFmpeg MP4 | 需单独安装运行时，手机与服务保持连接 |
| 保留真实而独特的表达 | 原话簿、来源快照、私藏转公开副本、系列 | 是否提升真实用户复用与付费仍待实测 |
| 小红书近日灵感 | 本人可见参考、最新 / 图文 / 一周内筛选 | 2026-10-09 实测六条；非全站榜，失效 / 验证会停止 |
| 免费开放设计来源 | 官方 GitHub Search / License API，MIT 证明 | 当时六个项目入待审核；需要独立适配及素材许可核对 |
| 公开插画 | 7 项固定 CC0 清单、文件与许可核验 | 当时六项通过，一项官网链接对应失败 |
| 自动更新灵感 | 本机计划任务与手动入口 | 需电脑运行；个人计划需成功手动验证并自行开启 |
| 防丢稿与容错 | 历史、撤销、旧结果保护、失败提示、备份与恢复 | 不替代用户定期保存私人备份 |
| 看见 AI 花费 | 用量账本、月预算、估算与手工对账 | 估价不等于账单，不保证云端总成本 |
| 不同网络、电脑关机也能用 | 部署方案已研究 | 用户已明确暂缓，未部署 |
| 多设备同步、多人账户 | 尚未实施 | 需要账户、隔离、同步冲突和服务端备份设计 |
| 商业性价比与差异化 | 验证方案与指标已写入规格 | 尚无真实付费或大样本效率结论 |

## 下一步按证据推进

1. 先由用户完成 iPhone 13 真机记录、照片、选页保存、备份恢复和外部参考审核。
2. 针对发现的问题修复；持续检查个人来源页面变化与 Peep 76 对应关系。
3. 使用自己的真实成稿对照常用工具，记录耗时、返工、导出成功和复用；按最初规格的门槛决定后续投入。
4. 如用户重新启动公网目标，再执行部署研究中的账号与资源准备，并重新核对当时的价格、条件和模型能力。
5. 模板扩展优先把少量许可清楚的候选适配成可编辑结构，不以候选数量代替可用性。

这份清单不把新需求自动排入开发，也不创建自动采集或日程任务。
