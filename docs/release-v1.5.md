## 使用与边界
刷新原手机入口，进入“我的 → 小拾与成长”；随心记上传照片后可确认拍摄日。从任意已有作品继续智能分镜、AI 润色、指定页保存，配置无需重填。

浏览器数据仍分设备 / 地址独立保存。请使用完整记录 ZIP 和作品 ZIP 备份真实内容；源码包不包含密钥和私人内容。当前需要电脑运行、同一 Wi-Fi，不能宣称电脑关机可用。

Edge 390×844、模拟键盘和 localhost PWA 不代表 iPhone Safari 真机验收。HEIC、长按选字 / 存图、分享和系统键盘应按新指南试用；公网账户、跨设备同步、实际小红书登录采集和商业效果仍是未交付的外部范围。
