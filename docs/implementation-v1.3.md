# 拾页 v1.3 实施准备：让积累支持持续创作

状态：承接已批准 docs/shiye-next-design.md；在 v1.2 整体审查 / 修复 / 归档完成后顺序实施。来源可行性正在通过 primary-source 联网研究核对。本文未宣称采集登录、云定时任务或外部模板已可用。

## 延续的产品定位
帮助用户积累、回看并表达自己的真实内容。外部参考提供结构启发与明确出处，不能取代自己的经历，也不以未经核实的爆款数值驱动焦虑。个人数据保留在本机，公开副本与私藏记录继续分离。

## 预定实现顺序
1. **来源与审核底座**：统一候选记录（类型、原始 URL、作者、发布 / 采集 / 核验时间、摘要、自写结构分析、互动数及核验时间、许可证据、引用范围、审核状态和原因）。去重、删除撤销、备份、失败保留；用户可先保存自己的链接与观察，未知字段显示未知。
2. **公开来源适配与任务状态**：从逐项可验证的免费 / 开放来源开始。手动与每日 09:00 Asia/Shanghai 触发同一任务入口，运行互斥、URL 去重、明确零新增 / 部分失败 / 待登录。私人账户只读采集由真实登录环境决定；验证码与平台限制需暂停，不能伪造成功或绕过。
3. **首页灵感与模板来源**：审核通过才展示。原始链接、时效与出处在卡片中可看；区分仅参考设计和可复用资产。已有 12 种原创模板继续可离线使用，外部样式只映射到支持的结构，不执行来源脚本。保存参考后可手选自己的记录，由 AI 提出新选题 / 草稿，并显示引用依据，原文保留。
4. **个人系列与发布回看**：把作品归到自己的系列，设置主题 / 语气 / 外观默认值并能覆盖；手动记录发布链接、发布时间与复盘（自报数据不冒充平台核验）。从自己已选记录中组织下次创作，不自动发布。
5. **成本与交付**：按实际请求记录可得的模型 token / 结果状态，费用由配置单价与来源时间估算并明确不是账单；可关闭 AI / 限额 / 取消，不做静默重试。保留总体服务器 + AI 每月不超过 100 元的目标，云成本需实际部署证据。
6. **整体复核**：来源时效、许可、审核可逆性、保存失败、队列幂等、离线与手机输入、个人素材选择边界、真实导出与备份完整回归；一次全阶段独立审查后修复和保留版本。

## 前置与可独立推进的工作
- v1.2 完成前只准备研究与接口，不改动正被审查的业务实现。
- 不等待用户账户即可实现候选 / 审核模型、明确来源的可用公共适配器、手动采样、个人系列及本机回看。
- 私人小红书登录验证、公网 HTTPS、账户隔离和电脑关机后定时更新需要真实外部条件；条件未满足时界面如实显示状态。后续在工作已具体可审阅时请求必要信息，不以时间经过当作授权。
- 先确认上一版备份 / 迁移接口，再增加数据存储；继续引用保护，不能因新增来源或系列而破坏随心记、回忆或作品。

## 待来源研究落定的决策
- 哪些官方接口 / 只读采集方式实际可用，哪些需要账户或平台授权。
- 首批外部资产的逐项许可、可再分发范围、署名与修改说明。
- 任务适配器首轮提供什么真实内容；不能把静态书签刷新时间显示为文章的发布时间，不能把采集失败写成零新增成功。

- Ruling：先实现手动来源和固定许可资产候选的真实审核通路，再接需要登录的自动采集；代价是首批首页没有未经验证的实时小红书热榜，但不会伪造时效或互动数。

### Task 1 开始前合同
- 候选模型：稳定 ID / 修订，reference 或 asset，原始与规范链接，来源与作者，发布时间可未知、采集 / 核查时间；摘要 / 结构分析；互动数保留原文、精度和观察时间；许可与署名证据；待审核 / 已通过 / 已拒绝 / 回收状态及理由。
- 审核必须是显式状态转换；新导入默认待审核，内容或许可证据变化后重新待审核；未经通过的记录不能出现在首页或模板可用列表。资产可复用与仅参考分开。
- 去重使用规范来源身份，保留可打开的原链接；修改与删除检查修订，失败保留原记录。恢复支持新增 ID，不能覆盖既有数据。
- 存储与自动任务独立于现有私人随心记，不读取全量私人记录发送到外部服务。服务器文件放到已拒绝公开访问的 .local 下，队列和数据写入串行、持久化原子提交。
- 先写失效审核 / 重复来源 / 修订冲突 / 损坏持久化 / 未审核不可见的失败测试，再实现模型和存储，随后接管理 UI。真实读取、写入和恢复各有证据再标 Task 1 complete。
- 后续只有用户手选的记录与当前参考可以进入 AI；不默认拼接全部历史，不自动发布。
