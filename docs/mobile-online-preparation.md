# 拾页手机长期使用：准备方案与操作路线

日期：2026-10-07。状态：用户已确认“无需同一 Wi-Fi、电脑可关机”，目前没有服务器或域名；本文件是购买前准备，云端尚未部署。v1.3.0 标签和源码归档保持不变。

## 这次要达到的结果

在 iPhone 13 的 Safari 中打开一个长期固定的 HTTPS 地址，使用移动数据也能记录、排版、调用 DeepSeek 和制作回忆短片。电脑关机不影响云端服务。先服务本人，已有内容保留；不把这次部署扩展为多人商业平台。

建议第一步继续将私人文字、照片和作品保存于当前手机浏览器。云服务器运行现有 Node 服务、AI 代理、来源检查与 FFmpeg；云服务器的持久目录保留来源库、公开插画缓存和用量账本。固定网址不等于自动云同步：换手机、清理浏览器或换域名仍需要内容备份恢复。

这是已确认目标下的首轮范围建议；用户若需要照片和记录自动跨设备同步，需要另外设计账户、数据备份与冲突处理，不悄悄把全部私人内容上传。

## 推荐资源与成本核对

优先考虑腾讯云中国内地轻量应用服务器，Linux、2 核 4GB；入门型 60GB SSD、5Mbps 峰值带宽、500GB 月流量的官方刊例为 65 元/月。这个选择为 Node 与单任务 FFmpeg 留出比 2GB 更多的内存空间，但仍须在实际机器完成短片测试。地域根据用户所在地与库存选就近的内地地域，备案完成后再绑定域名提供服务。

按服务器 65 元 + AI 预算 20 元 + 域名每年不超过 100 元的准备上限，月均约 93.33 元。这是采购预算计算，不是实际扣款或费用保证；超额流量、额外磁盘、备份服务等需单独计价。域名按年付款，腾讯云内地轻量用于备案时，累计购买至少 3 个月（含续费），备案期间剩余至少 1 个月；按常规价首次 3 个月服务器为 195 元，域名另计。不能把“月均”当成首次总付款。[备案云资源要求](https://cloud.tencent.com/document/product/243/18908)

官方有不同类型套餐和促销资格。只有登录后的订单明确显示价格、期限和续费规则，才使用活动价预算；不根据首页最低价替用户下单，也不把一次优惠续费称为永久同价。

香港入门型 2 核 2GB、40GB、20Mbps、512GB 月流量的刊例为 38 元/月，可以作为少备案等待的试验备选。但同一官方价格页明确说明：香港入门型无法保障内地跨境公网质量，可能出现较大延迟和丢包；2GB 上的完整短片也尚未实测。因此不把这个低价方案直接称为最适合长期使用。

## 旧内容怎么迁到固定网址

浏览器存储按协议、主机名和端口区分。旧的 http://192.168.77.8:5173 与新 HTTPS 域名属于不同存储空间；更改访问地址不会自动转移 IndexedDB。[浏览器存储说明](https://developer.mozilla.org/en-US/docs/Web/API/Storage_API/Storage_quotas_and_eviction_criteria)

在仍能看到旧作品的 Safari 地址中：

1. “我的 → 随心记与记录备份”，下载全部记录备份；包含回忆快照及引用照片。
2. “创作”中分别备份要保留的作品；作品备份包含页面、引用照片和发布回看。
3. “我的 → 个人系列与发布回看”，下载系列定义备份。
4. 需要保留自己的参考库和费用记录时，分别导出来源备份和 AI 用量账本。用量导出是留底，不直接作为新服务器的可导入账本。
5. 文件保存在 iPhone“文件”中。打开新网址后按各入口恢复，核对记录数、照片、单图导出及系列归属，再继续使用。确认成功前不清空旧站数据。

私人浏览器备份不会因为部署自动上传服务器。需要 AI、选材聊天或视频时仍按界面明确选择和发送。手机 Safari 与添加到主屏幕后的使用容器也必须实测数据是否一致；如不一致，在最终长期使用的入口恢复一次，不假定共享。

## 部署前我需要完成的工程工作

代码检查发现当前本机版不能直接作为公网版本暴露：

- `server/index.mjs` 只接受 localhost / 本机 IP；需明确固定域名与受信任反向代理的边界。
- 现有 8 位连接码用于局域网试用，且每次重启变化；云端需本人的私有登录和服务端会话，未经登录不能调用计费或管理接口。不能只开放 5173 到互联网。
- `.local` 是真实持久数据，不可放在部署重建就丢失的临时目录；应用发布、密钥配置与运行数据应分开，重启和回滚都要验证。
- FFmpeg / ffprobe 目前在 Windows 已验证；Linux 包、视频输出、内存峰值和运行超时要在所选服务器重新验证。
- 目前没有 Docker、Caddy 或 systemd 部署文件；需要制作与核对部署包、自动启动、日志、健康检查和服务器备份恢复方式。不能将这份准备文档称为已完成部署。
- 单人云端版本保留现有 AI 预算、来源审核和视频队列，不顺便增加多人注册或付费功能。

拟采用：固定域名 → Caddy HTTPS → 本机回环监听的 Node 生产服务；持久目录和后台任务在同一台小服务器中运行。Caddy 能自动申请和续期公共域名证书，前提是 DNS 正确、80 / 443 可达、证书数据目录持久可写，不必先购买付费 SSL。[Caddy 官方说明](https://caddyserver.com/docs/automatic-https)

## 何时算真正完成

按顺序取得实际证据后再交付：

1. 域名、服务器和必要备案已就绪，HTTPS 在 iPhone Safari 没有证书警告。
2. 不登录不能使用 AI 或读取管理数据；自己的登录、退出和过期提示可用。
3. 电脑关机、iPhone 关闭 Wi-Fi 使用移动数据，仍能打开固定网址并完成记录、图文导出、AI 和短片。
4. 服务器重启后恢复服务，预算账本和来源库仍在，不把缺失账本或中断费用当作零。
5. 在正式服务器用测试素材验证最长 12 页 / 30 秒短片、下载、取消、超时及临时文件清理。
6. 新网址成功恢复旧内容；完整备份可下载，未删旧站内容。
7. 记录第一次真实账单、套餐余量和 AI 用量，再判断是否长期达到每月 100 元目标。
