# AI 用量与预算：本机试用说明

入口：**我的 → AI 用量与预算**。这一页需要连接运行拾页的电脑；局域网连接码在启动窗口中，每次重启会变化。作品、随心记和本地排版不依赖此页联网。

## 第一次使用

1. 输入电脑的 8 位连接码，点“重新读取用量与设置”。这里不需要填写 API Key。
2. 查看本月估算、手填核对、生成中 / 未知费用预留，以及可用预留额度。月份按北京时间计算。
3. 默认 AI 月预算为 **20 元**。可修改为 0～100 元；0 会阻止新的 DeepSeek 调用。服务器月计划可留空；填写的是计划，拾页没有读取云账单。
4. 需要暂停所有新模型请求时，取消“开启 AI 调用”并保存。已开始的生成请回原入口取消，取消不代表供应商没有扣费。
5. 预算或单价修改只有点“保存预算设置”成功后生效。另一窗口已修改时，本页会保留输入并拒绝覆盖；重新读取前会确认是否丢弃未保存输入。

## 费用是什么

费用显示来自两部分：模型实际返回的 token × 当次保存的单价，以及你查看官方账单后手填的核对金额。它们都不能冒充自动获取的官方账单。没有返回 usage 的请求保留预留，标为费用待核对；不会把取消、断网或无效响应当作免费。

2026-10-05 实际读取 [DeepSeek 中文官方价格页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)：`deepseek-flash` 高峰人民币单价为缓存命中输入 0.04、未命中输入 2、输出 8 元 / 百万 tokens。拾页默认统一采用这组高峰价，不自行猜测节假日与折扣；缓存分项未知时按未命中计。可以在“查看与调整模型单价”中更新模型、三项单价、来源和核对日期。修改不追溯重算旧请求。

调用前，以实际请求 UTF-8 字节数加 4,096 余量、最大输出 tokens、未命中输入单价计算预留。图片也包含在请求中，预留可能明显高于真实用量。此方法用于控制本工具额度，**不是最终扣费上限保证**；供应商的计量、价格变化和本工具之外的调用仍需核对。模型名与计价模型不匹配时会阻止付费调用。

Ollama 没有 API 费用；有返回时仍记录其 token。电费、电脑资源、云服务器、第三方工具、官方赠送余额，以及启用账本以前的调用，均没有自动纳入。

## 取消、未知费用与对账

- 在“最近请求”查看结果、模型、输入 / 输出 token、当次单价日期。
- “只看费用待核对”包含较早月份的未知费用，不受最近 100 次列表影响；每核对一批，会补入更早的记录。
- 点击“核对这笔费用”，打开官方用量平台，核对后输入这笔总费用、日期并勾选确认。确认没有扣费可填 0。
- 手填金额替代本条的估算或预留，原 token、状态与单价快照仍保留；已核对金额可再次修正。
- 用量保存失败时已生成的文案保留，当前服务暂停新的 AI 调用。先检查电脑存储并重启，再到本页查看是否留下中断 / 未知费用；不自动再调用模型。

## 保存范围与导出

电脑开发端与生产预览端共用 `.local/ai-usage/usage.json`。使用文件互斥与原子替换处理并发；账本损坏时停止新 AI 请求并保留原文件，不重置成零。运行中丢失账本也会阻止调用。

“导出用量账本”下载完整 JSON，包括单价快照和手填核对记录。只记录计量、时间、功能与结果状态，不保存文案、日记、照片、模型回复或密钥。当前页面最多展示最近 100 条；账本最多 20,000 条，达到上限会在调用前停止，需导出并在电脑整理。

服务器 + AI 每月 **不超过 100 元**仍是产品预算目标，尚不是已验证的云端运营成本。当前为本机个人工具，连接码不是多人在线账户系统。

## 验证记录

使用独立合成文字做过一次真实调用：输入 214、输出 60 tokens；按上述配置估算 **¥0.000908**。开发端和预览端读取到同一条记录。没有使用用户私人日记；这个金额不是官方账单核验值。
