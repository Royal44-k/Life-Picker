# 拾页 · 移动图文工作台

状态：2026-09-28，本地 MVP 设计与可验证假设。用户提出移动端、图文批量生成、商业性价比；用户随后确认首版由自己在 iPhone 13 试用，并要求 AI 润色/生成（含符号和颜文字）。PWA、无账号本地优先为当前实现。

## 要解决的任务
面向已有成稿、每周持续发布的中文知识博主与文案创作者。将文字/Markdown 转为风格统一的多页图片，减少逐页复制、分页与排版返工。首版不以 AI 写作或自由拖拽为主要任务。

## 证据与取舍
- Canva 官方帮助说明 Bulk Create 将数据字段连接模板，当前仅桌面端可用：[官方帮助](https://www.canva.com/help/bulk-create/)。这是移动流程的切入点，不证明付费需求。
- MD2Card 已提供主题、自动分页、免费基础功能、API/MCP：[官网](https://md2card.com/en)。因此“Markdown 转图”本身缺少差异化；本产品的效率优势仍需实际对照实验。
- 选择 React + TypeScript + Vite PWA：一个代码库实现手机/桌面和浏览器 Canvas 排版，排版本身无推理调用成本；新增 Node 本地服务负责 AI 代理。原生 Expo 有更好的原生集成但首版分发与平台验证较多；微信小程序触达便利但需独立平台适配。
- 安装与分享依浏览器不同；manifest/HTTPS 是生产发布准备项：[安装说明](https://web.dev/learn/pwa/installation)，[文件分享接口](https://developer.mozilla.org/en-US/docs/Web/API/Web_Share_API)。生产手机访问不能依靠 localhost。

## 首版范围
1. 粘贴文字，编辑基础 Markdown（标题、段落、粗体、列表、引用、代码）；`---` 显式分页。其他语法保持可见文字，绝不执行 HTML。
2. 同一 Canvas 排版模型驱动预览与 PNG 导出；支持中文、长段落和无空格长串，分页不丢文本。超长标题完整参与分页。
3. 4 套中文主题、3:4/1:1/9:16 比例、字号、强调色、账号署名与品牌默认设置。
4. 翻页和缩略图检查，修改原文即时重排。显示实际页数、分页提示。
5. 1080 像素宽 PNG 单页导出，单篇所有页面 ZIP；多文件导入和多篇草稿批量 ZIP。手机支持时提供系统文件分享；提供可长按的单图预览。
6. 本地自动保存及明确失败提示，草稿保存/打开/删除，导出 Markdown 备份。数据不上传；清除浏览器数据将丢失本地草稿。
7. manifest、图标与生产资源离线缓存。无远程字体依赖。
8. AI 润色与主题生成：DeepSeek 官方 API、Ollama 本地接口、免费手动提示词路径。选择语气、长度和符号密度，返回结果先预览/可编辑，应用为新草稿。API Key 仅电脑进程环境或 .env，手机用临时连接码；请求限流、校验、75 秒超时、取消传播与无自动重试。模型数据去向在生成前说明。

## 约束和边界
- 单篇最多 20,000 字符，最多 60 页；最多 20 篇草稿；多文件单次最多 10 篇、每个 80 KB。超限拒绝且说明，不静默截断。
- 无登录、支付、自动发布或平台账号连接。AI 支持是用户新增范围；正式商业化另行实现账号、支付、合规与服务监控。
- 基础 Markdown 为明确子集；不承诺完整 CommonMark、公式、嵌套表格或外链图片。
- 手机原生相册写入与各应用分享目标不受网页完全控制；需真机验证。

## 工作流与架构
Source → Block[] → 字形测量/换行 → CardLayout[] → 同一 drawCard → PNG → 单图/ZIP/系统分享。
纯逻辑负责解析、断行、分页；Canvas 负责测量与绘制；UI 负责编辑与选择；存储负责受限且校验过的草稿；导出模块负责文件与资源释放。长操作显示进度并禁止重复启动。

## 视觉方向
白色纸张、冷灰底色 #F5F6FA、深墨 #202335、主紫 #7155D9、浅紫 #ECE7FA、灰字 #7D8191。正文使用本地中文无衬线，卡片可切换宋体；不下载远程字体。桌面三栏工作台，手机分为内容/样式/预览，固定底部操作。特色是直接可用的中文卡片作品与连续页缩略图，不加营销装饰。

## 技术验收
- 非空正常输入能够生成且导出；空白输入显示指引；不允许下载过时预览。
- 内容守恒测试覆盖长中文、emoji、长英文串、显式分页与代码块；配置变化后不越界。
- 导出 PNG 宽 1080，高由比例决定；ZIP 的张数与当前页数一致，文件顺序明确。
- 草稿刷新恢复；损坏/超额存储不让应用崩溃；多文件输入原子校验。
- 390px/桌面 UI 可用，键盘焦点、按钮名称、对比与减少动画设置有效；无横向页面溢出。
- 生产构建、自动测试、浏览器实操与导出文件检查全部记录，真机和商业测试单独标为未完成。

## 商业验证（待真实执行，非已有数据）
招募 8–12 位每周发 ≥3 篇的知识创作者，收集他们自己的 3 篇成稿；按交叉顺序对照现有工具与本工具。计时从成稿导入到实际可发布图片，记录分页改动次数、是否重做、导出成功与 7 天内复用。
继续投入门槛：至少 8 位完成任务，时间中位数降低 ≥50%，至少 6 位无需外部工具返工，至少 4 位 7 天内复用，至少 3 位愿意购买实测套餐。未达标先访谈失败原因，避免扩张模板库。
价格仅是假设：基础排版免费；品牌套件与批处理可测试 ¥19/月与 ¥39/月两档，先收预约意向，不伪造支付。单次客户端排版没有模型 API 费用，仍有开发、客服、分发和托管成本。上线前用实际流量、导出成功率和支持成本测算。

## 生态使用
Codex skills 用于需求收敛、实现计划、界面设计与验证；浏览器工具用于真实交互检查。暂不接入额外 MCP 依赖；等用户需要自动化后，再把同一文档/主题输入包装为 API/MCP，避免将免费的转换能力误当壁垒。
