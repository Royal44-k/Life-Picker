## 本次变化
- 小拾在页面编辑中依据当前文字、角色和照片存在情况解释排版选择，给出两个问题；手写回答只追加到当前未锁定页。无后台模型调用，可撤销与历史恢复。
- 回忆册新增开场、逐段过渡、结尾编辑器。原记录快照与日期/照片/顺序不被串联操作改写。实际画面预览、人工核对、应用草稿、确认保存分开。
- 可选 DeepSeek 串联仅接收明确展示的当前册文字、日期和照片数量；严格 JSON 与原片段 ID/顺序校验，可取消，无自动重试；统一用量与预算新增“回忆串联”，共七类云 AI。
- 修改本册选材、标题、照片或顺序会让旧串联待核对，无法直接导出。草稿保留，可重新核对或明确移除过渡和结尾；撤销、旧相册、备份恢复及新身份映射兼容。
- 图文单页/整册、公开作品、短片复用同一个确认版本。公开副本单独检查串联内容并重新确认，原私藏册不变。
