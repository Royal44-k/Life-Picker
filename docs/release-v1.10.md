# 拾页 v1.10.0 — 外部来源连接
基线：v1.9.0 / 3147c19。范围：本机来源连接；公网继续暂停。

- 系统 Edge 独立本机目录、用户正常登录；经可见网页只读最多六条小红书参考。不调用内部签名接口，不运行被 Windows 拦截的旧辅助程序。
- 近期搜索核对最新、图文、一周内的可见选中状态和笔记 DOM 刷新。未知发布时间保留未知，来源仍需人工概括和审核。
- GitHub 官方匿名 Search / License 接口发现最多六个 MIT 项目，保存实际许可原文、blob 标识和 SHA-256。它们是待适配源码参考，不执行项目代码、不自动增加可用模板。
- 公开插画对已复现的 TCP 连接错误仅同地址重试一次，总超时不变；HTTP 拒绝、TLS、重定向、许可和文件校验失败不重试。
- 候选列表在内存保留一天或至服务重启；已入库记录与许可证明持久化。现有 14 种结构和 7 项插画清单未虚增。
- 接口缺失、登录响应、权限、取消、晚到启动、重复导入、未保存编辑均已 RED→GREEN；搜索页面不同链接、作者日期混排、隐藏控件、选中标签变化和复用节点刷新有浏览器回归。
- GitHub 实测取得 6 个项目及 6 份 MIT 许可；实际接口与一手文档见[研究报告](research-external-connectors-2026-10-09.md)。
- 小红书不是官方爆款 API，网页改版、网络和账号状态可导致单次失败。每日计划仅电脑开机可运行，不默认启用。
- 无新增付费 AI 调用，不部署公网，不发送消息或发布。iPhone 13 Safari 真机体验仍由用户验收。

主服务验收、最终测试与归档校验记录在本次验收文件中。v1.9 标签与归档保留。
