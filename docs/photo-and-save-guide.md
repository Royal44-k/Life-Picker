# 照片与单图保存：本轮修复

- **删除照片**：素材 → 照片下方“删除” → “移入回收站”。可以立即“撤销删除”，也可从素材页右上角回收站恢复。
- 已被作品使用的照片移入回收站后，作品中的图仍保留。要永久删除，先在对应作品的分镜编辑中将“搭配照片”改为“不放照片”，等待保存完成后再回收；永久删除仅影响拾页副本，不删除 iPhone 原图。
- **保存指定图片**：点“保存单图”，在顶部“选择要保存的图片”选页，或点上一张/下一张。确认“第 N 张”与图片相符后，长按图片存到相册，或点“下载 PNG”。文件名包含对应页码。
- 分镜列表每一项也有下载按钮，直接打开该分镜的首张图；长页产生的续页仍可在保存弹窗中逐张选择。
- 如果顶部提示“修改尚未保存”，先点“重试保存”或按错误说明处理。不会将失败的修改提示为已保存。当前设备的照片与作品仍需定期通过“备份作品”留存副本。

此记录对应 v1.1.1 开发分支的修复节点。结构模板、单页 AI 和后续随心记仍在继续开发。
