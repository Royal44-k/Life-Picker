# 从最初对话到 v1.10：需求与决策演变

来源：本任务用户消息、保留的设计文档、发布记录与 Git 标签。按阶段归纳，不冒充逐字聊天记录；未记载的日期不补造。需求提出日期与实际打标签日期可能不同，准确版本提交见[版本档案](../archives/README.md)。

## 1. 最初目标：成稿之后，少花时间做图

2026-09-28，用户提出面向移动端的小红书 / 图文内容批量视觉化工具。目标人群是知识博主与文案创作者，痛点是文字完成后仍需在 Canva 等工具逐页排版。用户希望利用需求筛选、工作流设计和 Codex 生态，把生活想法落实为有商业性价比的产品。

首位试用者就是用户本人，设备为 iPhone 13，开发经验有限，因此交付必须包括具体启动、联网、配置与保存操作。首版采用手机网页 / PWA、React / TypeScript / Vite、Canvas、本机 Node AI 代理。用户确认手机能够打开首版，随后确认首版功能正常，并要求标记 v1、长期保留。

最初的 MVP 规格、范围与商业验证假设保留于 [product-spec.md](product-spec.md)。

## 2. AI 文案：可选、可检查、保留自己的表达

用户追加润色、按主题生成、特殊符号与颜文字，并询问免费开源模型。方案形成三条路径：DeepSeek API、本机 Ollama、免费手动复制提示词。用户在本机保存密钥，完成真实生成验证。仓库只包含配置示例，不发布密钥或历史连接码。

随着图片、记录、分镜和回忆进入工作流，AI 扩展为手选素材的内容建议。原文与照片由用户掌握；返回内容先预览确认，不直接覆盖当前编辑，不默认发送全部历史。

## 3. 差异化定位：持续积累真实而独特的内容

用户要求研究行业与竞品，并明确认可“帮助用户持续积累并表达自己真实而独特的内容”。产品因此从一次性转图扩展为个人素材与持续表达流程：

参考 → 照片与随心记 → 原话与经历 → 选题 → 多页作品 → 手动发布 → 系列与回看。

用户提出：首页近期灵感、开放模板广场、随心记、萌属性数字人、保存奖励及聊天。随后继续追加多入口上传图片、按周月年生成回忆、数字人引导创作。小拾最终采用原创二维纸页精灵，以 SVG / CSS 实现本地动作；聊天和编辑能力接入已有 AI 服务，避免仅为外形增加付费数字人依赖。

[完整设计方案](shiye-next-design.md) 保留智能分镜、图片共享、回忆、小拾、首页与开放来源的完整目标。

## 4. 智能分镜：把一篇文章组织成连续阅读的多页作品

用户提出按 Markdown 标题与内容切分为“封面—目录—核心观点—图表—封底”的 6～9 页流。实现选择以规则组织、实际字体测量和内容保全为基础，可选 AI 提供结构建议。

6 / 9 是软目标；短文不补造内容凑页，长文允许续页或拆册。页面编辑后，预览与导出使用同一份确认内容。用户明确授权按顺序开发，逐步完成 v1.1 至 v1.10。

## 5. 真实试用纠偏：图片可删除，单图可选页

v1.1 试用中用户指出：上传图片没有删除入口；单图下载总是首页，不能自主选页。v1.1.1 围绕这两项反馈增加移除、撤销与引用保护，以及明确页码选择和同源导出。

这成为后续共同原则：可恢复、可检查、失败不丢稿、旧结果不覆盖新编辑。历史恢复、来源更新差异、备份冲突、取消与重复操作保护持续沿用这一原则。

## 6. 逐步补齐个人创作流程

| 阶段 | 主要交付 |
| --- | --- |
| v1.1 / v1.1.1 | 多页作品、照片、分镜、单页编辑；用户反馈修复 |
| v1.2 | 随心记、共享素材、小拾、回忆图文与短片、四入口、备份 |
| v1.3 | 来源与审核、经历变选题、个人系列、发布回看、AI 用量预算 |
| v1.4 | 原话簿与公开作品副本 |
| v1.5 | 小拾装扮成长、情境引导、照片日期、基础整合与审查 |
| v1.6 | 可靠编辑、历史恢复、原文局部更新、AI 设置一致 |
| v1.7 | 实测容量、用途建议、排版诊断、长文拆册 |
| v1.8 | 两组开放主题适配、素材扩展、实际画面视觉建议 |
| v1.9 | 当前页追问与手写补充、回忆串联、图文短片同源 |
| v1.10 | 本人正常 Edge 可见参考、GitHub MIT 设计发现及真实入库 |

用户曾追问 v1.5 是否已经完成完整方案，之后按照差距表继续实现 v1.6～v1.10。因此保留“当前完成范围”，而不以“最终版”字样代替逐项验收。

## 7. 公网目标明确，但已暂缓

2026-10-07，用户选择“不同 Wi-Fi、电脑可关机”的目标，并表示没有服务器或域名。形成部署研究与从零准备说明后，用户明确暂缓该板块，要求继续其他功能。

当前没有购买云服务、注册域名、部署公网账户或跨设备同步。本次上传 GitHub 只保存项目资产，不代表重新启动公网部署。

## 8. 外部连接由用户本人正常授权登录

2026-10-09，用户要求连通小红书和开放设计来源，并配合专用 Edge 登录、关闭窗口以释放本机资料。系统防护拦截过旧辅助程序；最终实现改用正常系统 Edge 可见网页，不修改防护、不提取 Cookie 或隐藏接口。

实际收录六条近期图文参考与六个许可确认的 GitHub 项目，全部先进入待审核区。小红书不是全站爆款 API；设计候选需要适配，不能与现有模板数量混算。7 项插画中 1 项对应关系失败被保留为失败状态。具体见 [v1.10 验收](acceptance-v1.10.md)。
