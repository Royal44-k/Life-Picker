# 拾页 v1.1.1 实施记录

本计划承接用户已批准的 docs/shiye-next-design.md；用户要求按顺序持续开发，采用当前会话实施并在末尾做独立审查。前一阶段为有实质进展：v1.1.0 已提交、标记、归档及验证。

## 本轮目的
把当前基础分页提升为可以解释、可以选择结构、可以可靠修改的图文编排；仍保持原文与手动页面分开，不因选模板或换颜色调用 AI。

## 共用约束
- 20,000 字符、60 张实际导出图片；6/9 页是软目标；原文不静默截断。
- 原图、本地照片和 v1/v1.1 归档保留；新增字段可缺省，旧备份可恢复。
- 模板是确定性布局，AI 不输出任意 HTML/JS/SVG。
- 来源版本过期时提示，不把旧位置当作当前证据。
- 手机优先；Canvas 预览与导出同源；日志及归档不含 API Key。
- 已批准的设计与开发授权继续有效。本轮采用头脑风暴技能复核意图和边界，不重复提出已回答的授权问题。

## 顺序与验收
1. [x] 内容结构与分页：原文位置/稳定块 ID/标题父子关系；短标题绑定正文；有界候选搜索优化分页；硬分页与代码字素守恒。测试插入不相关内容后的 ID、跳级标题、长代码、密度与确定性。
2. [x] 最终目录：条目引用页面 ID，经过实际分页后显示页码；重排、删除、续页、比例变更时更新；手工改目录则转为手工文本。测覆盖目录页自身溢出和删除目标。
3. [ ] 12 个结构模板：大标题、引语、书摘、短文、清单、步骤、对比、数据、时间线、照片杂志、手绘便笺、成果总结。内置原创结构，带来源说明；保留用户文字、照片与锁定；图解无合适数据则明示回退，不捏造数值。每类渲染和备份兼容验证。
4. [ ] 单页 AI：只发送当前页与用户勾选的原文片段；展示候选和原文，确认才应用；锁定拒绝、可取消、过时版本拒绝覆盖、失败保留当前页；与整篇入口同认证及费用边界。
5. [ ] 手机交互与验收：模板缩略图、编辑器结构选择、来源查看；运行单元/接口、关键浏览器和真实导出；检查截图；独立审查并修复；更新操作指南与版本记录。

## 接口与依赖检查
- 内容索引是所有来源引用及目录定位的基础；先实施并测试，再修改 planner。
- 页面字段 template、sourceVersion、sourceRanges、tocEntries 为可选，旧作品采用默认值；backup 校验与 UI 同步，避免存入后无法恢复。
- 页面 ID 是目录跳转目标；重排不改 ID，重建匹配时需重新映射目录目标。
- layoutStory 为唯一计算最终页码的位置；渲染/导出不各自计算不同目录。
- 单页 AI 复用既有 handler 的连接码、同源、大小、并发、取消，不新增供应商或额外凭据。
