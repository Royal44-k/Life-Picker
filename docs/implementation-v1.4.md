# 拾页 v1.4：原话成为自己的创作素材

2026-10-07。承接已批准的 `shiye-next-design.md` 中“原话收藏”和私人记录到公开副本的流程。云部署、购买与注册按用户要求暂缓。v1.3.0 标签及源码归档保持不变；本增量在 `codex/personal-quotes` 开发。

## 本轮交付合同

1. 随心记增加“摘一句原话”。先完成当前保存，再从只读原文中选择片段，或点选系统按句号 / 换行拆出的原句。只能收藏原文中确实存在的文字；每句 1～500 字符，每条记录最多 20 句，同一记录不能重复收藏。没有 AI 改写或模型请求。
2. 原话作为记录内的可选 `quotes` 字段，保存文字、稳定 ID、收藏时间和当时记录日期。不变更数据库版本，旧记录仍然可读。修改原文后保留原话快照；原文不再包含这句话时明确提示。原记录回收时原话隐藏，恢复后可见；永久删除前说明原话也删除。
3. “我的”和随心记列表可打开原话簿，搜索、回到出处、移除和撤销最近移除。保存失败不得显示成功或先丢弃界面内容；跨窗口变更用既有 revision 防止覆盖，并提供重新读取。
4. 最多选择 9 句，显式检查可编辑公开文案后另存新作品。只带入选中原话，不自动附带原记录全文、标签、图片、其他收藏或私密 ID；不自动发布。生成前重新核对所选原话仍有效，失败保留编辑内容供下载或重试。
5. 现有完整 / 筛选记录 ZIP 备份包含原话；恢复为新记录后来源仍正确。错误字段导致整包拒绝，不能悄悄丢掉坏数据。离线继续可读写收藏并生成本机作品。
