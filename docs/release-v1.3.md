# 拾页 v1.3.0 发布记录

2026-10-05。本机个人试用版本；在 v1.2.0 的记录、回忆和图文基础上，补齐持续创作工作流。旧版标签和源码归档保留。本版不代表公网服务、小红书实时榜单或完整商业上线。

## 新增与完善

- 来源候选、出处 / 时间 / 观察数据、使用范围和许可证据；审核通过才展示，编辑后重新待审核，回收可恢复，备份合并与损坏修复保留原文件。
- 固定官方 CC0 插画检查：3 张真实核验 PNG，每日 09:00 或手动检查，新增 / 重复 / 部分失败如实显示。真实候选仍待用户审核。
- 首页已审核参考、收藏与结构分析；结合手选 1～3 条随心记文字生成选题和可编辑草稿，显示段落依据，核对后另存新作品，原记录保留。
- 开放插画与 12 种原创结构结合；先看实际 Canvas 排版再另存，图像和作品原子保存，原图及出处进入备份，已存本机作品可离线导出。
- 个人系列的主题、语气、默认外观和下一篇；已有作品可归类并保留自身样式，默认设置变化不改旧篇，停用可恢复，定义单独备份。
- 发布回看：手填链接、日期、观察指标、心得和下一篇想法，未知不等于 0，明确未经平台核验，随作品备份。
- 五类 AI 的共享用量账本、默认 20 元月预算、总开关、预留额度、实际 token、带日期单价估算、未知费用核对与导出。取消或无用量不当作免费，没有自动付费重试。
- 新手机指南在首页 / 我的“使用指南”，旧指南保留；v1.1.1 的图片移除 / 撤销和选任意页单图保存继续回归通过。

## 整体审查

一次独立只读审查覆盖 v1.2.0 后的整个 v1.3（38fd1a4..88631af），无 Critical、2 项 Important、无需要处理的 Minor。两项已集中修复在 **574dec5**：

1. 月末边界的月份与时间戳使用同一次时钟读取，避免把有效请求变成不可读账本。专项测试在单次预留期间跨月先失败再通过。
2. 来源 / provenance 的编码登录参数可能透传。改为共用检测与清理，兼顾嵌套百分号编码和邻近错误转义；同类发布链接一并覆盖。普通查询 ID 与安全锚点保留；不重置用户数据。

详细 Ruling、测试偏差与被审查者暂不判断项目的处理，见 [v1.3 实施记录](implementation-v1.3.md)。没有进行第二轮重复独立审查。

## 数据与版本保留

- 沿用 IndexedDB version 2；系列定义放在 meta，作品增加可选系列 / 发布 / 素材来源信息。没有替换旧作品或升级为不兼容数据库。
- 个人作品、记录与照片在当前浏览器；来源、公开素材缓存和用量账本在电脑 `.local/`。不是自动云同步。
- 系列定义单独备份，作品备份保留逐篇快照。来源恢复重新待审核；用量 JSON 是导出留底，不自动导入为官方账单。
- 源码 ZIP 不含真实 .env、API Key、浏览器私人数据、.local 运行时、node_modules、FFmpeg 或验证产物。解压到新目录后 npm ci、重新配置 .env，构建后运行；FFmpeg 另见短片运行时文档。
- 继续保留 v1.0.0、v1.1.0、v1.1.1、v1.2.0 和各自归档；经典入口 ?classic=1 使用独立旧存储。测试旧源码应使用独立地址 / 浏览器环境，不删除当前数据库来降级。

## 尚需真实条件的部分

- 小红书个人正常登录只读采集尚未连接。本版提供手动参考和固定开放插画，不能称作近日爆款或全站热榜。
- 未部署公网 HTTPS、多用户账户隔离、跨设备同步、电脑关机后采集；实际云账单尚未验证。服务器 + AI 每月 100 元是目标。
- iPhone 13 的 HEIC、键盘、滚动、保存单图、系统分享 / 保存 MP4，留给最终真机试用。局域网 HTTP 不等同 HTTPS / localhost 的 PWA 环境。
- AI 段落来源可检查，但事实正确性仍需人核对；不保证流量或商业转化。
