# 拾页 v1.5 本机最终整合版实施计划

承接已授权的 docs/shiye-next-design.md 和用户“完成最终版”。使用 executing-plans 按顺序实施，每阶段先验证失败，再实现；最后一次整版本独立审查。v1～v1.4 保留。分支 codex/local-final，基线 ce0e237。

## 最终范围
补齐方案中可在当前环境独立完成的小拾外观成长、记录情境引导、回忆入口和照片拍摄日期确认；完成全产品回归、操作指南与源码留档。公网部署、账号注册 / 购买继续暂停，真实小红书登录采集仍未连接；不伪称实时热榜、云同步或电脑关机后可用。

沿用 React / TypeScript / Canvas / IndexedDB / SVG / CSS。小拾不引入外部数字人平台。照片日期采用 exifr 7.1.3 本地读取，官方说明：https://github.com/MikeKovarik/exifr ，只请求 DateTimeOriginal、禁用 GPS，不把文件修改时间冒充拍摄日期，不因时区转换移动日历日期。无法读取时保留未确认状态。

## Task 1：小拾成长与兼容存储
- 新增 companion-profile.ts 和 companion-store.ts。meta 库固定键保存版本、revision、所选装扮和已获得纪念。读失败不静默重置；写失败不显示成功。
- 两款基础书签始终可选；收藏第一句原话后开启花朵邮票，保存第一本回忆或积累 30 页后开启星光。纪念包括第一条记录、第一句原话、第一本回忆、10 页和 30 页积累。
- 只根据真正保存的记录核对纪念，不以聊天、连续打卡或付费为条件。已经收好的纪念不因删除、停用或间隔天数撤回。
- 新旧窗口更换装扮用 revision 检查；刷新进度只合并纪念，不覆盖装扮。资料库损坏显示可恢复错误。
- 完整随心记 ZIP 增加可选 companion 字段；旧包仍兼容，筛选和单本回忆备份不带全局偏好。恢复记录与小拾信息在同一事务，合并纪念、保留本机已保存装扮，冲突时不部分写入。
- 测试：真假保存 / 单调成长 / 解锁条件 / 非法字段 / 新旧备份 / 原子恢复 / 写入失败 / 跨窗口修订冲突。

## Task 2：可见陪伴与记录到回忆的引导
- 扩展现有 PaperSpirit 的书签配色、花朵邮票、星光装饰，保留安静奖励、隐藏、键盘避让和 reduced-motion。
- 新增“我的 → 小拾与成长”，可预览、保存装扮、查看纪念；显示真实读取 / 保存状态，可重读，脏编辑和写入过程受导航保护。
- 随心记的小拾按当前文字 / 照片给出本地问题，明确只是提问，不冒充看懂照片或模型分析；沉重记录保持安静。
- 提供整理当前页为公开副本、按当前记录月份进入回忆选材的操作，先完成记录保存，未保存或失效日期不偷偷改变范围。AI 仍是用户主动聊天和手选素材。
- 测试：手机选择 / 刷新 / 冲突 / 存储失败 / 已获纪念不撤回 / 减少动态 / 隐藏 / 键盘 / 引导不产生模型请求 / 月份与用户调整正确。

## Task 3：照片拍摄日期确认
- prepareAsset 只在本机读取有效的 DateTimeOriginal，保存可选 capturedDate，依然重编码图片并清除原 EXIF / 定位。读取失败不阻碍可解码图片上传。
- 随心记选图后显示可采用的拍摄日期；多张不同日期逐项选择，不自动覆盖用户记录日期。无法读取时明确说明日期未确认。已经采用后可继续手动修改。
- 在作品 / 记录备份和恢复校验中保留并验证日期；旧素材无日期照常工作。公开 PNG 与 AI 图片只用现有重编码副本，不附带元数据。
- 测试：真实 JPEG EXIF、非法 / 缺失 / 未来或无效日期、不同日历日、损坏 EXIF、上传及压缩移除 EXIF、候选选择与不自动修改、备份字节和日期往返。

## Task 4：最终整合、审查与交付
- 建立需求完成矩阵：已实现 / 环境暂停 / 真机待验收，各项能对应入口与验证证据，不用旧设计基线描述当前实现。
- 运行完整模块套件、全部浏览器主流程、存储恢复套件、生产 PWA、真实 PNG 与 MP4 导出。使用隔离浏览器上下文 / 临时来源库，不修改用户内容，不发起不必要付费模型请求。
- 一次整版本独立审查，确定性问题先复现再修复；随后保留 v1.5.0 标签、逐文件校验源码 ZIP 和手机最终使用指南。
- 更新原 5173 入口，保留旧构建 / 旧散列资源。现有 DeepSeek 配置保留，仍按本机同 Wi-Fi 方式试用。
- iPhone Safari / HEIC 和商业小范围试用不能由桌面自动化替代，指南列出短验收路线。
