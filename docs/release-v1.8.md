## 取舍和后续
- 只读列表/搜索元数据足够形成引用候选；上游详情会重试并输出含令牌的日志，因此不开放，代价是需要用户自己概括原文。
- 系统 HTTPS 客户端是同一固定发布地址的有界下载备用方式，不改来源和摘要校验。完整浏览器依赖保留在项目目录，进程专属 LOCALAPPDATA 仅用于缓存隔离，不更改系统环境或指纹/代理。
- 开放主题是现有 Canvas 的署名适配，不承诺直接导入任意设计网站布局。
- 含锁定页时固定全篇颜色，代价是无法给未锁定页独立主题；当前数据结构是全篇配色。
- 本增量仍不是完整目标结项。继续小拾分镜解释、回忆串联叙事和真实 AI 检验；用户扫码和真机验收单列。
