# 拾页 SHIYE

面向手机的个人创作工具：把自己的文字、Markdown 和照片编成多页图文。当前为 v1.1.1 试用工作台，经典 v1 仍保留。

## 在 iPhone 上试用

1. Windows 打开 `D:\Codex-chat-II`，双击 **启动拾页.cmd**。
2. 保持启动窗口运行，iPhone 与电脑连接同一 Wi-Fi。
3. iPhone Safari 输入窗口显示的手机地址；换网后以窗口为准。
4. **新建作品 → 写下原文 → 生成分镜 → 素材添加照片 → 检查每页 → 保存单图 / 整篇 ZIP**。
5. 点击底部“使用指南”，按图文步骤操作。电脑可打开 [新版指南](http://localhost:5173/guide-v1.1.html)。

电脑入口：http://localhost:5173 。服务未启动时无法访问。当前仍为局域网试用，电脑需保持运行；公网 HTTPS 部署待环境准备后执行。

## v1.1.1 已实现

- 原文与作品页面分别保存。按 Markdown 章节、显式分页和实际文字尺寸编排；6/9 页是软目标，短文不凑页、长文增加续页。
- 可选封面、目录和结尾；单页文字编辑、移动、锁定、拆分、合并及最近操作撤销。
- 照片导入、自动缩放、页面选图、取景调整、删除/撤销/回收站。已被作品引用的照片不能永久删除。
- 层级金字塔、步骤、对比、时间线、清单。标签装不下时回到完整文字显示，并提示原因。
- AI 编辑成篇确认后另存新作品；单页 AI 仅发当前页和手选上下文，提供对照/编辑/应用/撤销/取消，旧结果不会覆盖变化后的页。原有 AI 润色、写文案仍可用。
- 12 个原创内置结构模板，先选择分镜并预览自己的内容再应用；颜色与结构分别调整，不调用 AI。来源索引及最终目录页码包含续页。
- 保存单图可明确选择任意一张，文件名标明页码；预览与 PNG / ZIP 使用同一份已编辑页面。作品 ZIP 备份包括原文、页面修改与被引用的照片；恢复为新作品。
- v1 草稿复制迁移，旧存储不改动。超出新编排容量的旧稿保留原文，提示拆篇或继续使用经典版。

v1 源码归档、校验信息及恢复步骤位于 `releases/`，本地 Git 标签为 `v1.0.0`。右上角“经典版”可继续使用原来的批量工作流。

## AI 配置

- **DeepSeek**：双击 **配置AI.cmd** 填写自己的 API Key，重启服务。手机仅填写启动窗口里的 8 位连接码。按量计费，仅在主动点击生成时调用，不自动重试。
- **免费手动**：原有 AI 文案面板可复制提示词到聊天工具，再粘贴结果。
- **Ollama**：原有文案能力支持本机模型；需要自行安装、下载模型并在 `.env` 设置 `OLLAMA_MODEL`。没有 API 调用费，但消耗本机算力。结构化 AI 分镜本轮使用 DeepSeek。
- 分镜默认只发送当前原文。勾选附图后，仅附带本作品使用的最多 3 张压缩照片；上传素材本身不会发送至模型。
- API Key 只在服务端，`.env` 不进入 Git 和发布归档。连接码在服务重启后变化。

模型、价格和图片能力以 [DeepSeek 官方文档](https://api-docs.deepseek.com/) 为准。AI 改写仍需自行核对事实、数字和经历。

## 保存与边界

- 草稿和照片保存在当前浏览器的 IndexedDB。手机、电脑、不同地址各有自己的存储；不等同云备份。
- 请定期下载作品备份。只在素材库而未放入作品的照片不会包含在单作品备份中。
- 每篇原文 20,000 字符，最多 60 张导出图片；照片每次最多 10 张、原文件 20 MB，入库最长边 2048；不支持解码的 HEIC 会提示转换格式。
- 支持基础 Markdown；复杂表格、公式和远程图片不完整渲染。设备字体可能影响特殊符号字形。
- HTTPS 或 localhost 正式构建可离线打开、编辑与导出；局域网 HTTP 不具备相同的 iPhone PWA 权限。AI 需联网且服务运行。
- 已验证 Chromium 的手机尺寸流程；iPhone 13 的新版长按存图、HEIC、分享菜单仍需真机检查。
- 随心记、小拾、回忆图文与短片、模板广场及灵感采集属于后续阶段，不能将本轮版本当作全部路线图已经交付。

## 开发和验证

Node.js 24+、npm；浏览器测试使用已安装的 Microsoft Edge。

```powershell
npm ci
npm run dev
# 另一个终端，开发服务保持运行
npm test
npm run test:e2e
npm run test:storage
node tests/studio-ai-browser.mjs
npm run build
```

正式模式与开发模式默认均占用 5173，不能同时启动。离线测试需正式构建服务：

```powershell
$env:PORT = '5181'
npm start
# 另一个终端
npm run test:pwa
```

`TEST_URL` 可指定浏览器测试地址；存储测试使用开发服务器。普通测试使用模拟 AI，不消耗 API 费用。实时 AI 调试脚本会调用真实服务并产生用量，不作为默认测试的一部分。

`src/studio/`：作品、照片、编排、持久化与新工作台；`src/core/`、`src/components/`：经典能力；`server/`：本地服务和 AI 代理；`docs/`：产品设计、实施记录、验证结果；`artifacts/`：本机验证产物，不入 Git。
