# 拾页 SHIYE

面向手机的个人创作工具：留下自己的文字与照片，再整理成可编辑的多页图文和回忆短片。当前为 **v1.2.0 个人试用版**，经典 v1 和 v1.1.1 均保留；外部灵感来源等 v1.3 功能继续按计划开发。

## 在 iPhone 上使用

1. Windows 打开 `D:\Codex-chat-II`，双击 **启动拾页.cmd**，保持窗口运行。
2. iPhone 与电脑连接同一 Wi-Fi，在 Safari 输入启动窗口显示的手机地址。换网后以窗口为准。
3. 首页点 **记下此刻**，写文字或添加照片；想做图时进入 **创作**，或从 **模板** 选一个原创结构开始。
4. 创作流程：**新建作品 → 写下原文 → 生成分镜 → 素材添加照片 → 检查每页 → 保存单图 / 整篇 ZIP**。单图弹窗可自主选择页码。
5. **我的 → 随心记** 可备份或恢复记录；**我的 → 回忆册** 可按周、月、年挑选记录，确认后导出图文或生成短片。
6. 完整图文步骤见 [v1.2 使用指南](http://localhost:5173/guide-v1.2.html)。电脑入口为 http://localhost:5173 。服务未启动时无法访问。

当前要求电脑运行且同一 Wi-Fi。公网 HTTPS、账户和跨设备同步尚未部署；不能把电脑上的记录自动当作手机上的记录。

## 这一版可用的功能

- **首页 / 模板 / 创作 / 我的** 四入口；真实本机最近记录和作品，本地灵感问题，保存失败时导航保留当前编辑。
- **随心记**：照片、文字、日期、标签、收藏、搜索、关联续记；自动保存、失败重试、回收恢复、完整备份。公开前检查独立副本，私藏标签不附带。
- **小拾**：原创 SVG 纸页精灵，本地提问、保存奖励、安静陪伴、隐藏与键盘避让。可手选记录与照片接入已有 DeepSeek 聊天，默认不发送历史记录。
- **回忆册**：周 / 月 / 年 / 自选范围，锁定、排除、换组和手动选材；确认后保存固定快照。可改写本册文字、移除照片、调整顺序；原记录保留。指定页 PNG / 全册 ZIP / 公开作品共用同一确认画面。
- **回忆短片**：15 / 20 / 30 秒，最多 12 页、每页至少 2 秒；720×1280 H.264，照片轻动、文字固定。默认无音乐，可选自制轻音。明确发送确认后在本机电脑编码，支持取消、超时提示、重试、同会话刷新找回、预览和 MP4 下载。
- **成稿到图文**：按 Markdown 章节、显式分页和实际文字尺寸编排，6 / 9 页为软目标；短文不凑页，长文自动续页。封面、目录、单页编辑 / 移动 / 锁定 / 拆分 / 合并 / 撤销，金字塔等基础图解。
- **12 种原创结构模板**：预览实际内容后另存作品或应用到选中页，颜色与结构分开调整。长文继续分页，不调用模型。
- **照片与导出容错**：移除、撤销、回收站、恢复；作品 / 记录 / 回忆仍使用的照片不能永久删除。单图明确选页，预览与导出同源，文件名带页码。
- **AI 辅助**：原有润色 / 写文案、整篇分镜、单页改写与小拾聊天。先看建议再应用，原文保留，可取消；旧结果不能覆盖已变化内容。

## AI 与短片配置

- **DeepSeek**：双击 **配置AI.cmd** 输入自己的 API Key 后重启服务。手机只填写启动窗口里的 8 位连接码。按量计费，主动提交才调用，不静默重试。
- **免费手动**：原有 AI 文案面板可复制提示词到聊天工具，再粘贴结果。
- **Ollama**：原有文案能力支持本机模型，需要自行安装、下载模型并设置 `OLLAMA_MODEL`；无 API 调用费，但消耗本机算力。结构化分镜和小拾当前接入 DeepSeek。
- 上传素材本身不发送给 AI；聊天最多手选 3 条记录与 3 张压缩照片。API Key 只在服务端 `.env`，不进入 Git / 源码归档，连接码重启后变化。
- 短片无需 AI 调用，但需要 FFmpeg / ffprobe。当前电脑已安装并校验，其他电脑的配置与来源见 [短片运行时说明](docs/video-runtime.md)。编码器不包含在源码归档中。
- 模型能力和价格以 [DeepSeek 官方文档](https://api-docs.deepseek.com/) 为准；改写后的事实、数字和个人经历需要自行核对。

## 保存、恢复与版本保留

- 作品、记录和照片存在当前浏览器的 IndexedDB，不是云备份；不同设备、浏览器和访问地址各自独立。清理浏览器数据或换地址前，先下载 ZIP 备份到“文件”。
- 作品备份包含该作品引用的照片；完整记录备份包含随心记、回收站、回忆快照和引用照片。仅在素材库、未被这些内容使用的照片不包含其中。
- 备份恢复创建新 ID，不覆盖已有内容；损坏 ZIP、缺图或冲突整体拒绝。恢复的回忆册无需额外改字即可导出，记录的续记功能与快照来源关系保留。
- 每篇原文 20,000 字符、最多 60 张导出图；一次最多上传 10 张照片，原文件最多 20 MB，入库最长边 2048。不能解码的 HEIC 提示转换格式。
- 短片完成后清理输入画面 / 临时配乐，成片约保留 10 分钟；仅当前浏览器会话可找回，请及时下载。电脑重启服务会清理旧作业。
- 已保留标签 `v1.0.0`、`v1.1.0`、`v1.1.1`；各版归档与校验在 `releases/`。经典版入口 `/?classic=1` 使用独立旧存储。
- 数据库已升至版本 2。旧 v1.1.1 源码不可强行降级打开当前同源数据库；回退应使用独立地址 / 浏览器环境并恢复兼容备份，不删除现有记录来降级。

## 验证范围

82 项单元测试、真实 IndexedDB 迁移 / 引用 / 恢复、经典及新版浏览器流程、真实选页 PNG / MP4 和生产离线检查已有证据。阶段审查及修复见 [v1.2 发布记录](docs/release-v1.2.md)。

Edge 的 390×844 视口、模拟键盘和 localhost 离线能力，不能代替 iPhone 13 Safari 的真机键盘、HEIC、系统分享体验。局域网 HTTP 不具备 HTTPS / localhost 同等 PWA 权限。模型效果、跨设备、云端采集和实际月费仍需真实条件验证。

## 开发与检查

Node.js 24+、npm；浏览器测试使用本机 Microsoft Edge。

```powershell
npm ci
npm run dev
# 在另一个终端执行，开发服务保持运行
npm test
npm run test:e2e
npm run test:storage
npm run build
```

正式与开发模式默认都使用 5173，不能同时占用；离线测试使用独立端口的正式服务：

```powershell
$env:PORT = '5181'
npm start
# 另一个终端
npm run test:pwa
npm run test:video
```

常规测试使用受控 AI，不消耗模型 API 费用；`test:video` 需要当前电脑的 FFmpeg。`TEST_URL` 可覆盖支持该参数的浏览器测试地址，存储和部分集成测试固定使用开发服务器 5173。

目录：`src/hub/` 四入口；`src/journal/` 记录 / 小拾 / 回忆；`src/studio/` 作品与排版；`server/` 本机服务、AI 和视频任务；`docs/` 方案与验证；`artifacts/`、`.local/` 为本机验证 / 运行时产物，不入 Git。
